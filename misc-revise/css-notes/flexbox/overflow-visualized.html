CSS Overflow — Visualized

When overflow works, when it doesn't, and what properties it depends on. The #1 cause of "overflow not working" is missing a constrained dimension.

1. What Overflow Controls — 5 values

overflow tells the browser what to do when content is bigger than its container. Each value behaves differently:

visible
overflow: visible
Content spills outside the box!
hidden
overflow: hidden
Content is clipped at the edge
scroll
overflow: scroll
Scrollbar always visible
auto
overflow: auto
Scrollbar only when needed
clip
overflow: clip
Clipped, no scroll possible
/* overflow shorthand = overflow-x + overflow-y */
overflow: visible;  /* default — content can spill out */
overflow: hidden;   /* clipped at the box edge */
overflow: scroll;   /* always show scrollbars */
overflow: auto;     /* scrollbars only when content overflows */
overflow: clip;     /* like hidden, but no programmatic scrolling */

2. The #1 Rule: Overflow Needs a Constrained Size — Without it, overflow does nothing

Overflow only works when the container has a constrained dimension. If the container can grow to fit its content, there's nothing to overflow.

This is the #1 bug: You set overflow: hidden expecting content to scroll, but the container has height: auto (default). It just grows to fit everything. Overflow needs a constrained dimension — either a fixed height, max-height, or a flex/grid constraint.

4. When Overflow Does NOT Work — Common failure cases

Failure case 1 — height: auto (the most common)
❌ You write this
.container {
  height: auto;  /* default! */
  overflow: hidden;
}
✅ What you need
.container {
  height: 400px;      /* or */
  max-height: 400px;  /* pick one */
  overflow: auto;
}
Failure case 2 — inline elements ignore overflow
inline span with overflow:hidden → ignored! 
span { overflow: hidden; } /* ❌ ignored */
inline-block works! 
span { display: inline-block;
       overflow: hidden; } /* ✅ works */
Failure case 3 — flex item won't shrink below content
Long text without min-width:0 → flex item won't shrink!
40px
.item { flex: 1; overflow: hidden; }
/* ❌ overflow won't work — item refuses to shrink below content */
With min-width:0 → flex item shrinks, overflow works!
40px
.item { flex: 1; overflow: hidden;
        min-width: 0; } /* ✅ key! overrides flex default */
Flex overflow rule: Flex items default to min-width: auto (won't shrink below content). Add min-width: 0 to allow shrinking + enable overflow/ellipsis.

5. Overflow With Text — white-space, text-overflow, word-break

Text behaves differently from other content. By default, text wraps to avoid overflow. You need extra properties to make text trigger overflow.

Default: text wraps
width: 150px
This is a long sentence that wraps naturally to fit the container. 
.box { width: 150px; overflow: hidden; }
/* text wraps — no overflow! */

Text wraps at word boundaries. No overflow despite hidden being set.

white-space: nowrap → forces overflow
width: 150px
This is a long sentence that CANNOT wrap → overflows! 
.box { width: 150px; overflow: hidden;
       white-space: nowrap; } /* prevents wrap */

nowrap prevents wrapping → overflow clipped!

Text overflow + ellipsis

text-overflow: ellipsis — requires 3 properties together
✕ Missing nowrap
This long text wraps and there's no ellipsis 
overflow: hidden;
text-overflow: ellipsis;
/* missing white-space: nowrap */
✕ Missing overflow
This long text spills over because no overflow:hidden 
white-space: nowrap;
text-overflow: ellipsis;
/* missing overflow: hidden */
✅ All three together
This long text gets an ellipsis because all 3 are set 
overflow: hidden;
white-space: nowrap;
text-overflow: ellipsis; /* ✅ */
Text-overflow: ellipsis requires all 3: overflow: hidden + white-space: nowrap + text-overflow: ellipsis. Missing any one → it won't work.
