1. display: flex Foundation

Flexbox is a one-dimensional layout model. Items sit along a main axis (horizontal by default) and optionally wrap to a cross axis.

15. Flexbox Mental Model & Responsive Strategy Mastery

Flexbox is powerful but easy to misuse. Here's the mental model you need to internalize, plus universal width/height rules for responsive layouts.

A. Axis Awareness — The #1 Concept

flex-direction determines which axis is main (where items flow) and which is cross (perpendicular). All alignment properties flip meaning based on this.

C. Universal Width & Height Rules for Responsive Sites

These patterns work everywhere — mobile, tablet, desktop — without media queries:

📦 Container fill
Make containers span full width, then let flex distribute
.container { width: 100%; max-width: 1200px; margin-inline: auto; }
📏 Fill remaining space
The universal "take what's left" trick
.fill { flex: 1; min-width: 0; }
📐 Side-by-side → stack
Row on desktop, column on mobile — no media query
.row { display: flex; flex-wrap: wrap; }
.col { flex: 1; min-width: 280px; }
📏 Full-height page
Sticky footer without hacks
body { min-height: 100vh; display: flex; flex-direction: column; }
main { flex: 1; }
🎯 Perfect centering
Both axes — works for any content size
.center { display: flex; justify-content: center; align-items: center; }
🔄 Auto margins
Push items apart without justify-content
.push-right { margin-left: auto; }
.push-bottom { margin-top: auto; }

F. Flexbox Decision Tree — Which Property To Use?

  ┌─ Want items side-by-side? ─→ display: flex
  │
  ├─ Want to change direction? ─→ flex-direction: column
  │
  ├─ Want to align along flow? ─→ justify-content
  │     (main axis)
  │
  ├─ Want to align perpendicular? → align-items
  │     (cross axis)
  │
  ├─ Want items to wrap? ───────→ flex-wrap: wrap
  │     + min-width on items
  │
  ├─ Want items to fill space? ─→ flex: 1 on items
  │     + min-width: 0 to allow shrink
  │
  ├─ Want gap between items? ───→ gap
  │
  ├─ Want to reorder visually? ─→ order
  │
  └─ Want per-item alignment? ──→ align-self
Golden rule for responsive width: flex: 1; min-width: 0; on children, flex-wrap: wrap on container. Handle spacing with gap. That's 90% of responsive layouts solved.
