1. The Default: Text Wraps — overflow-wrap: normal

By default, text wraps at word boundaries (spaces). Long unbroken strings overflow the container. This is the starting point for all text behavior.

The problem: Normal text wraps fine at spaces. But URLs, long words, and code strings don't have natural breakpoints. They overflow the container. The properties below fix this.

2. white-space — Controls wrapping & whitespace collapsing

Controls how whitespace (spaces, tabs, newlines) is handled and whether text wraps.

white-space: normal
Multiple spaces collapse. Newlines are ignored. Text wraps normally. 
/* default — collapses whitespace,
   wraps at container edge */
white-space: nowrap
Multiple spaces collapse. Text does NOT wrap. Single line. 
/* no wrap — single line.
   Used with text-overflow */
white-space: pre
Spaces kept. Newlines kept. No wrap. 
/* like <pre> — preserves
   spaces, newlines, no wrap */
white-space: pre-wrap
Spaces kept. Newlines kept. Text wraps. 
/* pre but wraps —
   best for code blocks */
Quick guide: Use normal for body text. nowrap for nav links + ellipsis. pre for code. pre-wrap for code that must wrap on small screens. pre-line for user-generated content with newlines.

3. word-break vs overflow-wrap — The #1 confusion

Both control how words break, but they differ in when they break words:

overflow-wrap: break-word (soft)
Only breaks a word if it would otherwise overflow. Prefers wrapping at spaces first. https://very-long-url-that-does-not-break.com/page 
.box { overflow-wrap: break-word; }
/* ✅ Best for general use
   Breaks only when necessary */

Breaks words only if they'd overflow. Normal words still wrap at spaces first.

word-break: break-all (aggressive)
Breaks at every character boundary even at normal words. This makes text harder to read. https://very-long-url.com/page 
.box { word-break: break-all; }
/* ⚠️ Aggressive — breaks
   EVERYTHING at any char */

Breaks words even when they don't need it. Use for URLs/code only.

word-break: keep-all (CJK)
For Chinese/Japanese/Korean text. Prevents breaks within words. Normal Latin text still wraps at spaces. 这是一个中文句子 
.box { word-break: keep-all; }
/* CJK text — prevents breaks
   within words */

For CJK languages. Latin behaves normally.

body     { overflow-wrap: break-word; }  /* ✅ safe for everything */
code,pre { word-break: break-all; }      /* ✅ for code blocks */

4. text-overflow — The ellipsis trio

Shows ... when text overflows its container. Requires all 3 properties to work.

✕ Missing one = broken
Missing white-space: nowrap
This long text wraps and there's no ellipsis
Missing overflow: hidden
This long text spills out because no overflow hidden
Missing text-overflow: ellipsis
This long text just clips abruptly with no visual indicator
✓ All 3 together = ellipsis
The magic trio:
This long text gets an ellipsis because all three properties are present and working together correctly 
.text {
  overflow: hidden;        /* 1. clip content */
  white-space: nowrap;     /* 2. prevent wrap */
  text-overflow: ellipsis; /* 3. show ... */
}
/* All three required — remove any → breaks */

This is the most common CSS trio. Memorize it.

5. text-wrap — New CSS property (modern browsers)

Controls how text wraps within a line, beyond just on/off. Newer than white-space.

text-wrap: wrap
Normal wrapping at word boundaries (default).
text-wrap: nowrap
No wrapping — same as white-space: nowrap
text-wrap: balance
Balances line lengths for headings — fewer ragged lines.
text-wrap: pretty
Optimizes the last line to avoid orphaned single words.
text-wrap: balance — before and after on headings
Without balance (default wrap)
This is a long heading that wraps naturally leaving a ragged right edge
With text-wrap: balance
This is a long heading that wraps naturally leaving a ragged right edge 
/* Best for headings — balances line lengths */
h1, h2, h3 { text-wrap: balance; }

/* Best for body text — avoids orphan words on last line */
p { text-wrap: pretty; }

6. hyphens — Adds hyphens at break points

Adds hyphens (-) when words break across lines. Makes justified text more readable.

hyphens: none (default)
This is a paragraph with no hyphens enabled. Words break without any visual indicator.
hyphens: auto
This is a paragraph with automatic hyphens enabled. Words break with hyphen character.

8. Decision Guide — Which property when

📝 Body text
p {
  overflow-wrap: break-word;  /* prevent overflow from long URLs */
  hyphens: auto;              /* optional: better justified text */
}
📰 Headings
h1, h2, h3 {
  text-wrap: balance;          /* balanced line lengths */
}
🔗 URLs / Code
code, pre {
  word-break: break-all;       /* break at any character */
  white-space: pre-wrap;       /* preserve formatting, wrap */
}
🔠 Single-line truncation
.truncate {
  overflow: hidden;
  white-space: nowrap;
  text-overflow: ellipsis;     /* ... */
}
📋 Nav links / buttons
nav a {
  white-space: nowrap;         /* prevent link text from wrapping */
}
📱 Multi-line clamp
.clamp {
  display: -webkit-box;
  -webkit-line-clamp: 3;
  -webkit-box-orient: vertical;
  overflow: hidden;
}

9. Quick Reference

PropertyValuesWhat it doesUse when
white-space normal nowrap pre pre-wrap pre-line Controls whitespace collapsing + wrapping Body text (normal), nav (nowrap), code (pre-wrap)
overflow-wrap normal break-word Breaks a word only if it would overflow ✅ Safe for body text
word-break normal break-all keep-all Aggressively breaks at character boundaries Code/URLs only (break-all), CJK (keep-all)
text-overflow clip ellipsis Shows ... when text overflows Truncation — requires overflow:hidden + nowrap
text-wrap wrap nowrap balance pretty Controls wrapping strategy Headings (balance), body (pretty)
hyphens none auto manual Adds hyphen at break points Justified text (auto), needs lang attribute
-webkit-line-clamp number Limits text to N lines + ellipsis Card descriptions, previews
Universal rule: Set overflow-wrap: break-word on your body (prevents URL overflow). Use white-space: nowrap on nav links. Use the trio (overflow:hidden + nowrap + text-overflow:ellipsis) for truncation. Use word-break: break-all only on code elements. 4 rules cover 95% of text-breaking needs.
