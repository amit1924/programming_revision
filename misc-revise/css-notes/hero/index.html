REQ min-height on
Gives the hero a minimum height so it's visually substantial. Without it, hero collapses to content height — no visual impact.
REQ display: flex + centering on
Flexbox centers content both horizontally and vertically. Without it, content sits at top-left — looks broken.
REQ background on
Sets the visual backdrop (color, gradient, image). Without it, hero is invisible against the page background.
REC overlay on
Darkens/highlights the background so text is readable. Without it, text may be unreadable against a busy background.
REC text-align: center on
Centers hero text for a balanced look. Without it, text is left-aligned — mismatch with centered layout.
REC responsive font sizes on
Uses clamp() or media queries to scale text. Without it, headings stay huge on mobile.

C. Without background-size: cover

✕ Without cover — image repeats

Image Repeats

Looks like a pattern, not a hero

/* default: repeat — tile pattern */
✓ With background-size: cover

Full Background

Covers entire area — professional

.hero {
  background: url(hero.jpg) center/cover no-repeat;
}

D. Without overlay — text unreadable

✕ Without overlay — text lost

Hard to Read

Text blends with background

/* text directly on image — hard to read */
✓ With overlay — readable

Clear & Readable

The overlay creates contrast

.hero::before {
  content: '';
  position: absolute;
  inset: 0;
  background: rgba(0,0,0,0.4);
  z-index: 1;
}

E. Without responsive font sizes

✕ Without — fixed font size

48px on mobile

Too large for small screens

.hero h1 { font-size: 48px; }
/* stays 48px on mobile — overflows */
✓ With clamp() or media query

Scales to fit

Looks good on every screen

.hero h1 { font-size: clamp(1.5rem, 5vw, 3.5rem); }
/* fluid: 1.5rem min, 5vw preferred, 3.5rem max */

3. The Three Hero Types — Color, Gradient, Image

Every hero uses one of these three background strategies. Each requires different CSS.

Solid Color

Simplest, fastest

.hero {
  background: #1a1a3e;
  /* No overlay needed */
}

Gradient

Modern, visually rich

.hero {
  background: linear-gradient(
    135deg, #1a1a3e, #5a1a3e
  );
}

Image

Needs overlay + cover

.hero {
  background: url(hero.jpg)
    center/cover no-repeat;
}
.hero::before {
  background: rgba(0,0,0,0.4);
} /* overlay */

/* === UNIVERSAL HERO CSS — copy this === */
.hero {
  min-height: 100vh;                /* 1. full viewport height */
  display: flex;                    /* 2. enable flexbox */
  align-items: center;              /* 3. vertical center */
  justify-content: center;          /* 4. horizontal center */
  text-align: center;               /* 5. center text */
  padding: 40px 20px;               /* 6. edge spacing */
  background: linear-gradient(      /* 7. visual backdrop */
    135deg, #1a1a3e, #3a1a5e
  ) center/cover no-repeat;
  position: relative;               /* 8. overlay anchor */
  overflow: hidden;                 /* 9. contain decorations */
}

.hero::before {                     /* 10. overlay for text readability */
  content: '';
  position: absolute;
  inset: 0;
  background: rgba(0,0,0,0.35);
  z-index: 1;
  pointer-events: none;
}

.hero-content {
  position: relative;               /* 11. above overlay */
  z-index: 2;
  max-width: 720px;                 /* 12. readable line length */
}

.hero h1 {
  font-size: clamp(1.8rem, 5vw, 3.5rem);  /* 13. fluid heading */
  color: #fff;
  font-weight: 800;
  margin-bottom: 0.5em;
}

.hero p {
  font-size: clamp(0.85rem, 2.5vw, 1.2rem); /* 14. fluid body */
  color: rgba(255,255,255,0.85);
  max-width: 540px;                 /* 15. limit line length */
  margin: 0 auto 1.5em;
}

.hero .btn {
  display: inline-block;
  padding: 12px 32px;
  background: #89b4fa;
  color: #0f0f17;
  border-radius: 8px;
  font-weight: 600;
  text-decoration: none;
  transition: all 0.2s;
}

.hero .btn-ghost {
  display: inline-block;
  padding: 12px 32px;
  color: #fff;
  border: 1px solid rgba(255,255,255,0.3);
  border-radius: 8px;
  font-weight: 500;
  text-decoration: none;
  transition: all 0.2s;
}

@media (max-width: 640px) {
  .hero { min-height: 90vh; }       /* 16. slightly shorter on mobile */
  .hero .btn,
  .hero .btn-ghost {
    width: 100%;                    /* 17. full-width CTAs on mobile */
    text-align: center;
  }
}
The hero formula: min-height: 100vh + flex centering + background + overlay + clamp() typography = a hero that works on every screen. 17 CSS declarations minimum.
