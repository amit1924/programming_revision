3. Responsive Navbar — Desktop → Mobile

A navbar must work on all screen sizes. The universal pattern: flex row on desktop, hamburger + column on mobile.

Resize your browser — or drag the slider below

width: 700px mode: desktop 
/* The responsive navbar pattern */
.navbar {
  display: flex;
  align-items: center;
  justify-content: space-between;
  padding: 0 20px;
}

.nav-links {
  display: flex;      /* horizontal on desktop */
  gap: 8px;
  list-style: none;
}

/* Mobile: stack vertically, hidden until hamburger clicked */
@media (max-width: 640px) {
  .nav-links {
    display: none;             /* hidden */
    flex-direction: column;    /* stacked */
    position: absolute;
    top: 56px; left: 0; right: 0;
  }
  .nav-links.open { display: flex; }
  .hamburger { display: flex; }  /* show hamburger */
}
Universal breakpoint: 640px or 768px is where most navbars switch from horizontal to hamburger. The key CSS: flex-direction: column on mobile + display: none / display: flex toggle with JS.

/* === UNIVERSAL NAVBAR CSS — copy this === */
.navbar {
  display: flex;                /* 1. items in a row */
  align-items: center;          /* 2. vertically centered */
  justify-content: space-between; /* 3. logo left, links right */
  padding: 0 20px;              /* 4. edge breathing room */
  background: #1e1e30;          /* 5. background color */
  min-height: 56px;             /* 6. minimum tap target */
  gap: 16px;                    /* 7. spacing */
}

.nav-links {
  display: flex;                /* 8. links in a row */
  align-items: center;          /* 9. vertically center links */
  gap: 8px;                     /* 10. space between links */
  list-style: none;             /* 11. remove bullets */
  margin: 0;                    /* 12. reset default ul margin */
  padding: 0;                   /* 13. reset default ul padding */
}

.nav-links a {
  text-decoration: none;        /* 14. remove underline */
  color: #a6adc8;               /* 15. link color */
  padding: 8px 14px;            /* 16. clickable area */
  border-radius: 6px;           /* 17. hover shape */
  font-size: 0.9rem;            /* 18. readable size */
  font-weight: 500;             /* 19. medium weight */
  transition: all 0.2s;         /* 20. smooth hover */
}

.nav-links a:hover {
  background: #2a2a40;          /* 21. hover feedback */
  color: #cdd6f4;
}

.nav-links a.cta {
  background: #89b4fa;          /* 22. call-to-action */
  color: #0f0f17;
  font-weight: 600;
}

/* Mobile */
@media (max-width: 640px) {
  .nav-links {
    display: none;              /* 23. hide on mobile */
    flex-direction: column;     /* 24. stack vertically */
    position: absolute;         /* 25. dropdown from navbar */
    top: 56px; left: 0; right: 0;
    background: #1e1e30;
    padding: 12px;
    border-top: 1px solid #2a2a3c;
  }
  .nav-links.open { display: flex; } /* 26. toggle with JS */
  .hamburger { display: flex; }      /* 27. show hamburger */
  .navbar { position: relative; }    /* 28. anchor for absolute menu */
}
Count them: 28 CSS properties/declarations make a complete, responsive, production navbar. Every single one has a purpose. Remove any → something breaks.

5. Quick Reference

CategoryPropertyWhy RequiredWithout it
REQ Layout display: flex Items sit in a horizontal row Items stack vertically
REQ Layout align-items: center Vertically center all navbar items Items stretch full height
REQ Layout justify-content: space-between Logo left, nav links right Everything clumps left
REQ Spacing padding: 0 20px Content doesn't touch screen edge Text hits the edge
REC List list-style: none Remove bullet points from <ul> Bullets before each link
REC Links text-decoration: none Remove underlines from nav links Links are underlined
REC Links padding: 8px 14px Creates clickable area around links Hard to click precisely
REC Links border-radius: 6px Smooth hover shape Sharp hover edges
OPT Spacing gap (or margins) Space between nav links Links cramped together
OPT Height min-height: 56px Minimum tap target size Navbar may be too short
OPT Hover transition: all 0.2s Smooth hover animation Abrupt hover changes
OPT Mobile @media (max-width: 640px) Responsive hamburger menu Broken on mobile
The universal navbar rule: Every navbar needs display: flex + align-items: center + justify-content: space-between + padding. That's the minimum. Add list-style: none, text-decoration: none, gap, a hover state, and a mobile breakpoint. 13 properties = a complete navbar.
