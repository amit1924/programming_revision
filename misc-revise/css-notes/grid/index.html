/* Column and row shorthand */
.item { grid-column: span 2; }  /* span 2 columns */
.item { grid-row: 1 / 3; }       /* from row line 1 to 3 */

/* or by line numbers */
.item { grid-column: 1 / 3; }    /* start at line 1, end at line 3 */
.item { grid-column: 2 / -1; }   /* from line 2 to the end */

13. Flexbox vs Grid When to Use Which

Flexbox
1D — row OR column. Content-first. Items wrap but don't align in both axes naturally.
Grid
2D — rows AND columns. Layout-first. Define the structure, then place items.
Use Flexbox for
Navbars, centering, inline elements, one-dimensional lists, small-scale layouts.
Use Grid for
Page layouts, card grids, dashboards, galleries, any two-dimensional arrangement.
They work together! A grid cell can contain a flexbox. A flex item can be a grid. Use each for what it's best at.
