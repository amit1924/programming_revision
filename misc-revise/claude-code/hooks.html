Hooks Deep Guide

Deterministic lifecycle callbacks that always fire — unlike Skills. Control every phase of a Claude Code session.

01

What are Hooks?

Skills are probabilistic — they may fire based on Claude's judgment. Hooks are deterministic — they always fire at specific lifecycle points. Hooks are your guarantee.

Skills

✗ Probabilistic — Claude decides

Hooks

✓ Deterministic — guaranteed execution
02

All Hook Events

Six lifecycle events where hooks can attach. Click any event for details.

S

SessionStart

Fires when a Claude Code session begins. Use for initialization, loading config, or setting up environment.

U

UserPromptSubmit

Fires after user submits a prompt. Pre-process input, inject context, rewrite queries.

P

PreToolUse

Fires before a tool is invoked. Validate arguments, block dangerous operations, transform parameters.

O

PostToolUse

Fires after a tool returns. Inspect results, log usage, transform output, trigger notifications.

T

Stop

Fires when a turn ends (after tool results are processed). Cleanup, summarize, persist state.

C

ConfigChange

Fires when hooks config or settings are modified. Hot-reload hook definitions.

03

Hook Types

Five hook type implementations — each with a different execution model.

⌨️
command
Runs a shell command synchronously. Access to stdin/stdout.
🌐
http
Makes an HTTP request to your endpoint. Async with JSON payload.
🔧
mcp_tool
Calls an MCP tool as a hook. Full MCP protocol integration.
💬
prompt
Returns a prompt string appended to the system prompt.
🤖
agent
Runs a sub-agent with its own instructions and tools.

05

Practical Examples

Real-world hooks you can use today. Click the copy button to copy any example.

⚡ Auto-format with Prettier

Auto-format files after every tool writes to disk.

# Runs after any tool that modifies files
hooks:
  PostToolUse:
    - command: "npx prettier --write ."
      onlyOnEventPayload:
        toolResult.isError: false

🛡️ Block Dangerous Commands

Intercept and block destructive shell commands.

# Block rm -rf / and similar commands
hooks:
  PreToolUse:
    - command: "sh -c '
      if echo \"$HOOK_TOOL_INPUT\" | grep -qiE \"rm\\s+-rf\\s+/\";
      then echo \"{\\"isError\\":true,\\"result\\":\\"BLOCKED\\"}\";
      else exit 0; fi'"
      onlyOnEventPayload:
        tool.name: "Bash"

🔔 macOS Notification

Get a native macOS notification when a long task completes.

# Notify on long-running tool completion
hooks:
  PostToolUse:
    - command: "terminal-notifier"
      args: ["-title", "Claude Code",
             "-message", "Tool completed!"]
      timeout: 5000

🔑 Env Var Injection

Inject environment variables from a secure vault into each session.

# Inject secrets from 1Password CLI
hooks:
  SessionStart:
    - command: "sh -c '
      export VAULT_TOKEN=$(op read
        \"op://vault/ci/token\" 2>/dev/null);
      echo \"{\\"envVars\\":
        {\\"VAULT_TOKEN\\":\\"$VAULT_TOKEN\\"}}\""
      timeout: 10000
