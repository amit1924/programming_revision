01

Dynamic Context Injection

The killer feature: !command in SKILL.md runs a shell command at load time and injects its output directly into the prompt. No hardcoding — live data, every time.

Common Injection Patterns

PatternWhat It DoesUse Case
!git diff --cachedInjects staged diffCommit skills
!cat package.jsonInjects project metadataSetup skills
!ls -la src/Injects file listingAnalysis skills
!node -e "process.version"Injects runtime infoEnv checks
!dateInjects current timestampLogging skills
!curl -s http://localhost:3000/healthInjects server statusHealth checks
$ git diff --cached
diff --git a/src/index.js b/src/index.js
+ console.log("hello world");

Subagent Skills context: fork

context: fork spawns an isolated subagent with its own context window — only the SKILL.md content is available. Main session stays untouched.

● Main Session Context
CLAUDE.md — project instructions
git info — branch, diff, log
Conversation history — 50+ messages
Open files — 4 tabs
Tool results — cached outputs
➞
◈ Forked Subagent (Explore/Plan)
SKILL.md — skill instructions only
!command results — injected at fork
No CLAUDE.md — isolated context
No conversation history — fresh start
⚡ Click "Fork Subagent"
SKILL.md — subagent skill 
---
name: explore
mode: auto
context: fork
description: Spawns isolated explore agent to investigate codebase
modelDescription: Explorer agent — reads files, maps structure
---
## Instructions
# This subagent runs in its own context window
# No access to main session conversation history
1. Explore the codebase structure
2. Identify key files and patterns
3. Report findings back to the main session
03

Arguments: $ARGUMENTS

When a user invokes a skill with /skill-name value, the $ARGUMENTS variable captures everything after the skill name.

$
Type a skill invocation above
$ARGUMENTS captured:
feat: add button
SKILL.md — with $ARGUMENTS 
---
name: commit
mode: auto
description: Create a commit with a custom message
---
## Instructions

# $ARGUMENTS contains everything after the skill name
# User types: /commit feat: add search
# $ARGUMENTS = "feat: add search"

The user wants to commit with message: $ARGUMENTS

1. Run `git add -A` to stage all changes
2. Run `git commit -m "$ARGUMENTS"`
3. Show the commit output

---
name: read-only-review
mode: auto
allowed-tools:
  - Read
  - Glob
  - Grep
  # Bash, WebSearch, WebFetch NOT allowed
---
## Instructions
Review the codebase for style issues and security concerns.
Do not modify any files.

Putting It All Together

An advanced skill using fork, allowed-tools, $ARGUMENTS, and dynamic injection simultaneously.

SKILL.md — advanced master skill 
---
name: audit
mode: auto
description: Full codebase audit with forked explorer
context: fork
allowed-tools:
  - Bash
  - Read
  - Glob
  - Grep
---
## Instructions

# Dynamic context: inject current state
!git diff --stat
!node -e "process.version"
!date

# $ARGUMENTS captures the user's specific focus
The user wants to audit: $ARGUMENTS

1. Use Read/Glob/Grep to explore relevant files
2. Run analysis with Bash tools
3. Report findings with severity ratings
4. Suggest fixes for each issue found
