0. Strings Are Indexed Foundation

Every character in a string has a zero-based index. The first character is at 0, the last at length - 1. Strings are immutable — methods return new strings, they never modify the original.

Visual index map — each colored block = one character

"Hello".at(-1)        // → "o"  (negative = from end)

charAt(i)
Returns char at index i, or "" if out of range. Old school.
at(i)
ES2022. Supports negative indices (-1 = last char). Returns undefined if out of range.
charCodeAt(i)
Returns the UTF-16 code unit (0-65535) at index i. For emoji/astral symbols, use codePointAt().
length
Property, not a method. Number of UTF-16 code units. Emoji like "😊" count as 2.

"Hello, World!".includes("World")     // → true  (case-sensitive)
"Hello, World!".startsWith("Hello")   // → true  (checks start)
"Hello, World!".endsWith("!")         // → true  (checks end)
"Hello, World!".indexOf("o")          // → 4     (first occurrence)
"Hello, World!".lastIndexOf("o")      // → 8     (last occurrence)
"Hello, World!".search(/world/i)      // → 7     (regex, returns index)
indexOf vs search: indexOf takes a plain string, search takes a regex. Both return the index or -1. search can't take a start position; indexOf can (indexOf("o", 5) starts from index 5).

⚠ substring vs slice critical difference:
"Hello".substring(-2, 3) → "Hel" (negative → 0)
"Hello".slice(-2, 3) → "" (negative counts from end = index 3 to 3 = empty)
"Hello".substring(3, 0) → "Hel" (swaps start/end!)
"Hello".slice(3, 0) → "" (does NOT swap)

5. Replace & Match replace · replaceAll · match · matchAll

Click presets to see replace behavior:
replace("dogs", "cats")
—
Only replaces first match (string or regex without /g)
replaceAll("dogs", "cats")
—
Replaces all matches. Accepts string or regex with /g.
match(/dogs/gi)
—
Returns array of matches or null. With /g = all, without = details.
search(/dogs/i)
—
Returns index of first match, or -1.
"cat cat".replace("cat", "dog")       // → "dog cat"  (only first)
"cat cat".replaceAll("cat", "dog")  // → "dog dog"  (all)
"CAT cat".replaceAll(/cat/gi, "dog") // → "dog dog"  (regex + flag)
"a1b2c3".match(/\d+/g)               // → ["1", "2", "3"]
replaceAll requires global flag: replaceAll(/cats/gi, "dogs") works. replaceAll(/cats/i, "dogs") throws TypeError! Use /cats/gi with the g flag.

6. Split string → array

split(separator) splits a string into an array. The separator can be a string or regex. The original string is unchanged.

String: Separator: Limit:
Source string
Result array
> "apple,banana,cherry,date".split(",")
⇐ ["apple", "banana", "cherry", "date"]
"a,b,c".split(",")          // → ["a","b","c"]
"a,b,c".split(",", 2)       // → ["a","b"]  (limit)
"hello".split("")            // → ["h","e","l","l","o"]
"a b  c".split(/\s+/)        // → ["a","b","c"]  (regex)
"".split(",")               // → [""]  (array with one empty string)
split("") splits into characters — useful for iterating over letters. But emoji like "😊" or "👨‍👩‍👧" are multiple code units — split("") breaks them. Use Array.from(str) or spread [...str] for proper Unicode.

7. Concat Joining Strings

concat() vs + vs template literals:
"Hello".concat(" ", "World")
"Hello World"
Joins strings. Rarely used — + is shorter.
"Hello" + " " + "World"
"Hello World"
Most common. Concise, but can be slower in loops.
`Hello ${name}`
"Hello World"
Template literals. Best for readability + expressions.
