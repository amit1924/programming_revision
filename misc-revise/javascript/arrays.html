0. Arrays Are Indexed Foundation

Arrays are zero-indexed ordered lists. Each element has an index. Mutable methods modify the array; immutable methods return a new array.

Visual index — each colored block = one element
Length: 5 elements
Mutating vs Non-mutating: push(), pop(), splice(), sort(), reverse() modify the original. map(), filter(), slice(), concat(), toSorted(), toReversed(), toSpliced() return a new array.

Stack operations — add/remove from the end. Fast (O(1)).

Queue operations — add/remove from the start. Slow (O(n)), reindexes everything.

// Transform — always returns a NEW array (immutable)
arr.map(x => x * 2)         // → [2, 4, 6, ...]  (1:1 mapping)
arr.filter(x => x > 2)      // → [3, 4, 5]  (keeps matches)
arr.flatMap(x => [x, x*2])  // → flattens one level
arr.reduce((acc, x) => acc + x, 0) // → single value
arr.forEach(x => console.log(x))    // → undefined (side effects)
map vs forEach: map returns a new array (use for transformation). forEach returns undefined (use for side effects like logging or DOM updates). Don't use forEach when you mean map.

6. Create & Fill Array.from · Array.of · fill · isArray

// Static methods (on Array, not on instances)
Array.from("hello")               // → ["h","e","l","l","o"] (iterable → array)
Array.from({length:3}, (_,i) => i) // → [0,1,2]  (map callback)
Array.of(1, 2, 3)                    // → [1,2,3]  (like [1,2,3] but safe)
Array.isArray([])                    // → true  (best way to check)

// Instance methods
arr.fill(value, start, end)         // → mutates, fills with value

7. Some, Every, Flat some · every · flat · flatMap

arr.some(x => x > 3)   // → true  (at least one matches)
arr.every(x => x > 3)  // → false (all must match)
arr.flat()              // → [1,2,3,4,5]  (from [[1,2],[3,4,5]])
arr.flatMap(x => [x])  // → map + flat in one pass
some stops early: If any element matches, iteration stops immediately (short-circuit). Same with every — returns false as soon as one fails. This makes them efficient for large arrays.
