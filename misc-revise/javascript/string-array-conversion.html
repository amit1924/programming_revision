1. String → Arraysplit · Array.from · spread

str.split(separator?, limit?)
"a,b,c".split(",") → ["a","b","c"]
Splits by delimiter. Supports regex separators. Limit param truncates result. Original string unchanged.
⚠️ "".split(",") → [""] (not []). Empty string with no separator: "".split() → [""]. "".split("") → [].
Array.from(str)
Array.from("hello") → ["h","e","l","l","o"]
Creates array from iterable. Unicode-safe — respects code points. Accepts optional map callback.
✅ Array.from("😊") → ["😊"] (1 element). Array.from("") → [].
[...str] (spread)
[..."hello"] → ["h","e","l","l","o"]
Same as Array.from — iterates via Symbol.iterator. Unicode-safe. Slightly faster syntax.
✅ ["😊"] works correctly. Same edge cases as Array.from.
Object.assign([], str)
Object.assign([], "hi") → ["h","i"]
Copies indexed properties from string to array. Not recommended — surprising behavior with sparse arrays and non-indexed keys.
⚠️ Copies length and other enumerable properties. Avoid unless you know what you're doing.

2. Array → Stringjoin · toString · String()

arr.join(separator?)
["a","b","c"].join("-") → "a-b-c"
Joins elements with separator. Default is ",". null/undefined become empty strings. Sparse arrays skip holes.
⚠️ [1, null, 3].join() → "1,,3". [1,,3].join() → "1,,3" (hole → empty). [].join() → "".
arr.toString()
["a","b","c"].toString() → "a,b,c"
Always uses "," separator. Calls toString() on each element. No separator customization.
⚠️ [[1,2],[3,4]].toString() → "1,2,3,4" (flattens! but shallow). [1,[2,[3]]].toString() → "1,2,3".
String(arr)
String(["a","b"]) → "a,b"
Exactly the same as arr.toString(). Also triggered by "" + arr or template literals `${arr}`.
Same edge cases as .toString().
arr.toLocaleString()
[1000,2000].toLocaleString("de-DE") → "1.000,2.000"
Locale-aware formatting. Useful for numbers/dates with region-appropriate separators.
Separator is locale-specific ("," in en-US, ";" in de-DE for array elements).

6. Cheat Sheet

// String → Array
str.split(",")               // → ["a","b","c"] by delimiter
str.split("")                // → ["h","e","l","l","o"] chars (NOT unicode-safe)
Array.from(str)               // → ["h","e","l","l","o"] (unicode-safe)
[...str]                      // → ["h","e","l","l","o"] (unicode-safe)
str.split("").reverse().join("")  // → "olleh" reverse a string

// Array → String
arr.join(",")                // → "a,b,c"
arr.join("")                 // → "abc" concatenate
arr.toString()                // → "a,b,c"
String(arr)                   // → "a,b,c"
"" + arr                      // → "a,b,c" implicit coercion

// Convert each element
arr.map(x => String(x))       // → ["1","2","3"]
str.split(",").map(Number)    // → [1,2,3] parse numbers

// Multi-char separator
"a||b||c".split("||")           // → ["a","b","c"]
["a","b"].join(" || ")          // → "a || b"
