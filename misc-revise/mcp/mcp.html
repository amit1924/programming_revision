1 What is MCP?

MCP (Model Context Protocol) is an open standard — like USB-C for AI. It lets AI models connect to external tools, databases, files, and APIs through one common protocol instead of writing custom code for each integration.

🤖 AI Model
MCP ← Standard Port
Tool / API
⚡ Gmail
USB-C analogy: Just as USB-C lets your laptop connect to monitors, keyboards, and phones through one port — MCP lets an AI connect to Gmail, GitHub, databases, and calendars through one protocol.

5 What MCP Servers Expose

Every MCP Server can expose up to 3 types of capabilities:

🔧 Tools

Actions the AI can trigger — send email, create repo, query database, book calendar

📄 Resources

Data the AI can read — file contents, database rows, API responses, logs

📝 Prompts

Pre-built templates — "summarize this PR", "analyze this log", "generate report"

8 Transport: How MCP Communicates

MCP uses JSON-RPC messages over different transports. Two main options:

📦 stdio Transport

Client spawns the server as a subprocess. Communication happens over stdin/stdout.

# Client launches server as a process $ node mcp-server.js # Messages over stdin/stdout: > {"jsonrpc":"2.0", "method":"tools/list"} < {"jsonrpc":"2.0", "result":{"tools":[...]}}
Local only Fast

🌐 HTTP + SSE Transport

Client connects over HTTP with Server-Sent Events for streaming responses.

POST /mcp HTTP/1.1 Content-Type: application/json {"jsonrpc":"2.0", "method":"tools/call"} // Server streams via SSE: event: message data: {"result":{"content":[...]}}
Remote Streaming
Try switching transport: Local subprocess — fast, simple, secure

10 Why Companies Adopt MCP

🧩 Less Code

Write one MCP server instead of N separate API integrations. Reuse across any MCP-compatible AI app.

🛡️ Less Maintenance

API changes? Update only the MCP server — all AI apps that use it work without changes.

♻️ Reusable

An MCP server written for Claude also works with any MCP-compatible host. No vendor lock-in.
