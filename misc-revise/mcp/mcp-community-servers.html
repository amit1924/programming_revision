Community MCP Servers

The ecosystem of 16,000+ servers built by the community — beyond the official reference implementations

Landscape snapshot (May 2026): 16,000+ servers across 4 major registries — PulseMCP (15,930+), Smithery (~7,300), Official MCP Registry (~2,000), GitHub (15,000+ repos). 14,000+ servers on PulseMCP alone. 02 Ecosystem Evolution

How the community MCP ecosystem grew from a few reference servers to 16,000+

Nov 2024
Anthropic releases MCP with 7 reference servers (filesystem, git, GitHub, PostgreSQL, etc.) — the seed of the ecosystem
Early 2025
Community explosion: hundreds of hobbyist servers on GitHub. awesome-mcp-servers list starts tracking them. First registries (Smithery, PulseMCP) appear
Mar 2025
OpenAI adopts MCP → inflection point. Streamable HTTP and OAuth 2.1 formalized. Vendor-maintained servers begin replacing community forks
Sep 2025
Official MCP Registry launches at registry.modelcontextprotocol.io — grows to ~2,000 servers within months
Dec 2025
MCP donated to Linux Foundation's Agentic AI Foundation. Vendor-neutral governance with Anthropic, OpenAI, Google, Microsoft, AWS
Jan–May 2026
Ecosystem reaches 16,000+ servers. PulseMCP grows 1,000+/month. AWS ships 60+ official servers. Remote MCP (hosted + OAuth) becomes the 2026 norm

05 The Big Shift: stdio → Hosted, API Key → OAuth 2.1

The ecosystem is mid-transition. Pre-2026 community servers use stdio + API key. Post-2026 vendor servers use Streamable HTTP + OAuth 2.1.

👴 Community (2024–2025)

  • ✗ stdio transport (spawn as subprocess)
  • ✗ API key or PAT auth
  • ✗ Manual npm/pip install
  • ✗ Local-only deployment
  • ✗ No SSO integration

🚀 Vendor (2026+)

  • ✓ Streamable HTTP transport
  • ✓ OAuth 2.1 with audience binding
  • ✓ One-click install via Claude Desktop
  • ✓ Remote/managed hosting
  • ✓ SSO-integrated auth flows

06 How to Install a Community Server

Most community servers follow one of these patterns.

📦 npm

# Install globally
npm install -g @modelcontextprotocol/server-github

# Or run with npx
npx -y @modelcontextprotocol/server-filesystem /path

Most TypeScript MCP servers publish to npm. Use npx for one-off runs.

🐍 pip / uv

# pip
pip install mcp-server-postgres

# uv (faster)
uv add mcp-server-postgres

Python servers use PyPI. uv is the recommended installer for Python MCP servers.

⚙️ Claude Desktop Config

// ~/.config/Claude/claude_desktop_config.json
{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y",
        "@modelcontextprotocol/
server-github"]
    }
  }
}

For Claude Code: claude mcp add commands.

⚠️ 2026 remote servers need no install. Many vendor servers (GitHub, Notion, Linear, Cloudflare, Atlassian) are remote endpoints — you authenticate via OAuth in the UI, no CLI install needed. In Claude Desktop, use Custom Connectors → enter the server URL → OAuth flow starts automatically.
07 ⚠️ Security — The Ecosystem's Weakest Link
🚨 April 2026: Systemic RCE vulnerability in all MCP SDKs. OX Security disclosed that all MCP SDK implementations (Python, TypeScript, Java, Rust) have a systemic RCE vulnerability via stdio transport. Estimated impact: 150M+ downloads, 7,000+ public servers. Anthropic responded that this behavior is "expected" and declined to modify the protocol architecture. Only install servers you trust.

🔴 High Risk

  • ⚠️ Shell/server exec: mcp-shell-server and equivalents — RCE by design
  • ⚠️ Filesystem servers with write access — data exfiltration risk
  • ⚠️ Unofficial forks of popular servers — no security review
  • ⚠️ Archived servers still being served via npm/PyPI — unpatched vulnerabilities

🟢 Safer Practices

  • ✅ Use vendor-operated remote MCPs (OAuth + hosted) when available
  • ✅ Run servers in Docker containers for isolation
  • ✅ Use Docker MCP Catalog — containerized with built-in isolation
  • ✅ Pin versions — avoid npx -y @latest — use explicit version tags
  • ✅ Prefer servers in both Official Registry + PulseMCP
