2 What Happens Internally?

🔧 Raw MCP Client — You Do Every Step

You manually control the entire lifecycle. Every step is explicit in your code.

1 Start the server process via stdio_client(server_params)
2 Create read/write pipes from stdio
3 Wrap pipes in ClientSession(read, write)
4 Call session.initialize() — handshake with server
5 Call session.list_tools() — discover available tools
6 Call session.call_tool(name, args) — invoke each tool
🚗 Manual car analogy: You start the engine, press the clutch, change gears, control the speed — you do everything.

🤖 LangChain MCP Client — Automatic

MultiServerMCPClient handles all the boilerplate internally. You never see the individual steps.

1 ✅ Starts the server process (hidden from you)
2 ✅ Creates the session (hidden from you)
3 ✅ Calls initialize() automatically
4 ✅ Discovers all tools automatically
5 ✅ Converts MCP tools into LangChain-compatible BaseTool objects
6 ✅ Returns ready-to-use tools — just call get_tools()
🚙 Automatic car analogy: You just press the accelerator. The car handles gear changes, clutch, and engine management for you.

4 Tool Calling Comparison

🔧 Raw MCP: You Call Every Tool By Name

You manually call each tool with its name and arguments.

# You decide which tool to call and when result1 = await session.call_tool("fetch_data", {}) result2 = await session.call_tool("process_data", {"input": result1}) # You must know: tool names, parameters, order of execution
You control the flow. The AI is not deciding anything — you are hardcoding the tool calls.

🤖 LangChain: AI Agent Calls Tools Automatically

Tools become LangChain BaseTool objects. An AI agent decides when to use them.

# Get tools — now they're LangChain tools tools = await client.get_tools() # Give tools to an AI agent agent = create_react_agent(llm, tools) # The AI decides tool calls automatically result = await agent.invoke({ "messages": [ {"role": "user", "content": "Get data and process it"} ] })

The AI decides. You just provide the tools. The LLM chooses fetch_data or process_data based on the user's request.

9 One-Sentence Summary

The Raw MCP Client is a low-level client where you manually manage sessions and tool calls, while the LangChain MCP Client is a high-level wrapper that automatically connects MCP tools to LangChain agents so AI models can use them directly.

🔧 Raw: You control everything 🤖 LangChain: AI controls the tools
