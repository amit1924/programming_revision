Flexbox Basics

flex: 1 vs no flex

The single most important layout property in React Native.

9:41
Flex Lab flex: 1 ON
Screen layout (parent = entire device)
Header (fixed height)
flex: 1 — fills remaining space
Footer (fixed height)
Real app layout
Header (fixed)
⬇️ Content fills all remaining space (flex: 1)
Footer (fixed)
flex: 1 tells the View to take up all remaining space inside its parent. The middle section stretches to fill everything between the header and footer.

Rule

flex: 1 → "Take all available space"
Without it, a View shrinks to fit its content (height: auto).
Parent needs height
flex: 1 on a child only works if the parent has a defined height — either flex: 1 on the parent or a fixed height.

Common patterns

// ✅ Full screen layout
<View style={{flex: 1}}>
  <Header />            // fixed height
  <FlatList style={{flex: 1}} />  // fills rest
  <Footer />            // fixed height
</View>

// ❌ Without flex:1
<View>  // height = content only
  <Header />
  <FlatList />  // might not scroll!
  <Footer />
</View>
💡 In React Native, the default flexDirection is column (not row like CSS). And flex: 1 is how you make a View fill the screen — there's no height: 100vh in RN.

The Only Code You Need

✅ With flex: 1 
<View style={{flex: 1}}>
  <Header />
  <FlatList style={{flex: 1}} />
  <Footer />
</View>

// ✅ FlatList scrolls properly
// ✅ Content fills screen height
Without flex: 1
<View> // ← no flex: 1!
  <Header />
  <FlatList />
  <Footer />
</View>

// ❌ FlatList might not scroll
// ❌ Footer gets pushed off screen
// ❌ Content collapses to fit
