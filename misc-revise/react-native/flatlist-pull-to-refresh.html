What's happening

Pull down on the list to trigger a refresh. The list simulates a 1.5s network request.

✅ Event Handling — The Full Flow

1
User pulls down on the list
Gesture starts when scrollY === 0 and finger drags downward. FlatList detects the overscroll.
2
onRefresh callback fires
FlatList calls your function. Inside it, you set refreshing = true to show the spinner.
3
Fetch new data (async)
Your API call runs. The spinner keeps spinning until you say stop.
4
setRefreshing(false) — spinner hides
Data is updated and the spinner disappears. List re-renders with fresh data.

⚠️ If you forget setRefreshing(false)

The spinner stays forever. The user is stuck with a spinning wheel and no way to dismiss it.

Quick Props Reference

refreshing boolean

Controls spinner visibility. You must toggle it.

onRefresh function

Called when user pulls down. Fetch data, then set refreshing to false.

refreshControl component

Alternative: pass a RefreshControl element for custom styling.

keyExtractor function

Unique key per item. Defaults to item.key then item.id.

Simplest Working Example

Just 3 things: state → handler → FlatList props.

App.tsx 
// ─────────────────────────────────────────────
//  1. IMPORTS
// ─────────────────────────────────────────────
import React, { useState, useCallback } from 'react';
import { FlatList, View, Text } from 'react-native';

// ─────────────────────────────────────────────
//  2. TYPE & INITIAL DATA
// ─────────────────────────────────────────────
type Item = { id: string; title: string };
const INITIAL: Item[] = [
  { id: '1', title: '🍎 Apple' },
  { id: '2', title: '🍌 Banana' },
  { id: '3', title: '🍒 Cherry' },
];

// ─────────────────────────────────────────────
//  3. COMPONENT
// ─────────────────────────────────────────────
const FruitList = () => {
  const [data, setData] = useState(INITIAL);
  const [refreshing, setRefreshing] = useState(false);

  // ─────────────────────────────────────────────
  //  4. HANDLER (the key piece!)
  // ─────────────────────────────────────────────
  const onRefresh = useCallback(async () => {
    setRefreshing(true);                          // 4a. Show spinner
    const res = await fetch('https://api.example.com/fruits');  // 4b. Fetch
    setData(await res.json());
    setRefreshing(false);                         // 4c. Hide spinner
  }, []);

  // ─────────────────────────────────────────────
  //  5. RENDER
  // ─────────────────────────────────────────────
  return (
    <FlatList
      data={data}
      renderItem={({ item }) => <Text>{item.title}</Text>}
      keyExtractor={item => item.id}
      refreshing={refreshing}           // ← required
      onRefresh={onRefresh}             // ← required
    />
  );
};
That's all you need for pull-to-refresh
refreshing + onRefresh = pull-to-refresh enabled

Code + Visual Breakdown

PROP refreshing boolean

A boolean that you control. When true, the refresh spinner is visible.

refreshing = true
Spinner ON
refreshing = false Spinner OFF
FlatList does NOT auto-set this. If you forget to set it back to false, the spinner spins forever.
PROP onRefresh () => void

Called when the user's pull gesture exceeds the threshold. Your job:

1. setRefreshing(true) // show spinner
2. await fetchData() // get fresh data
3. setRefreshing(false) // hide spinner
Always wrap with try/finally so step 3 runs even if step 2 throws an error.
ALTERNATIVE refreshControl

Use this instead of refreshing/onRefresh when you need platform-specific styling:

<FlatList
  refreshControl={}
    <RefreshControl
      refreshing={refreshing}
      onRefresh={onRefresh}
      tintColor="#fff" // iOS
      title="Loading..." // iOS
      colors={['#blue']} // Android
    />
}
IMPORTANT keyExtractor + extraData

keyExtractor — must return a unique string per item. FlatList uses it for React keys. Default: item.key → item.id → index.

extraData — if renderItem depends on state outside data (e.g., a selected ID), pass it here. FlatList is a PureComponent and won't re-render otherwise.

// Without extraData, FlatList skips re-render
<FlatList
  extraData={{selectedId}}
  renderItem={{({item}) =>
    <Text style={{color: item.id === selectedId ? 'blue' : 'black'}}>
      {item.title}
    </Text>
  }
/>

Production-Ready Pattern

App.tsx — with error handling 
import React, { useState, useCallback } from 'react';
import { FlatList, RefreshControl, View, Text, StyleSheet } from 'react-native';

type Item = { id: string; title: string };

const App = () => {
  const [data, setData] = useState<Item[]>([]);
  const [refreshing, setRefreshing] = useState(false);

  const fetchData = async () => {
    const res = await fetch('https://api.example.com/items');
    if (!res.ok) throw new Error('Network error');
    const json = await res.json();
    setData(json);
  };

  // ✅ try/finally ensures spinner ALWAYS stops, even on error
  const onRefresh = useCallback(async () => {
    setRefreshing(true);
    try {
      await fetchData();
    } catch (err) {
      console.error(err);  // Log it, show toast, etc.
    } finally {
      setRefreshing(false);  // ✅ Always runs
    }
  }, []);

  return (
    <FlatList
      data={data}
      renderItem={({ item }) => (
        <View style={styles.item}>
          <Text style={styles.title}>{item.title}</Text>
        </View>
      )}
      keyExtractor={item => item.id}
      refreshControl={
        <RefreshControl
          refreshing={refreshing}
          onRefresh={onRefresh}
          tintColor="#89b4fa"
          colors={['#89b4fa', '#a6e3a1', '#f9e2af']}
        />
      }
    />
  );
};

const styles = StyleSheet.create({
  item: { padding: 16, borderBottomWidth: 1, borderBottomColor: '#313244' },
  title: { fontSize: 16, fontWeight: '600' },
});

export default App;

✅ Best Practices Checklist

useCallback on onRefresh

Prevents unnecessary re-renders.

try/finally to dismiss spinner

Guarantees refreshing=false even on error.

Always provide keyExtractor

Stable keys = stable list performance.

Use getItemLayout when possible

Skip measurement for fixed-height items.

extraData for external state

Force re-render when needed.

RefreshControl for custom UI

iOS titles, Android colors, etc.
