AsyncStorage

Simple key-value persistent storage. Like localStorage for React Native.

API Reference

await setItem(key, value) // string only
await getItem(key) // → string | null
await removeItem(key)
await clear() // removes everything
await getAllKeys() // → string[]

Storing Objects

// AsyncStorage only stores strings
// Use JSON.stringify / JSON.parse

// Save
await setItem('user', JSON.stringify({
  name: 'Alice',
  age: 25
}));

// Read
const raw = await getItem('user');
const user = raw ? JSON.parse(raw) : null;
💡 Important: All methods are async. Always use await. AsyncStorage is global — data persists even after app restart. Max storage varies by platform (~6MB on Android).

Minimal Example

App.tsx 
import AsyncStorage from '@react-native-async-storage/async-storage';

// Save a string
await AsyncStorage.setItem('username', 'alice');

// Read it back
const name = await AsyncStorage.getItem('username');
// name = 'alice'

// Save an object
await AsyncStorage.setItem('user', JSON.stringify({
  name: 'Alice',
  age: 25
}));

// Read object
const raw = await AsyncStorage.getItem('user');
const user = raw ? JSON.parse(raw) : null;

// Delete
await AsyncStorage.removeItem('username');

// Clear everything
await AsyncStorage.clear();
