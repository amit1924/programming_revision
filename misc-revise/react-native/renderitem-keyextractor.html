The Code

App.tsx 
// data — the array
const data = [
  { id: '1', name: '🍎 Apple' },
  { id: '2', name: '🍌 Banana' },
];

<FlatList
  data={data}

  // ✅ renderItem — what each card looks like
  renderItem={({ item, index }) => (
    <View>
      <Text>{index + 1}. {item.name}</Text>
    </View>
  )}

  // ✅ keyExtractor — unique key per item
  keyExtractor={item => item.id}
/>
PROP renderItem

A function that receives an object with:

item // the current element from data[]
index // position in the array
separators // highlight/unhighlight helpers

Returns a React element (JSX). That's your list item UI.

PROP keyExtractor

Returns a unique string for each item. React uses it to track additions, removals, reorders.

// Default (if you skip it):
item.key → item.id → index
// Best practice:
keyExtractor={(item) => item.id}
Bad keys cause all items to re-render on every update. Always use a stable, unique ID.

⚠️ Never use index as key

If items are reordered, deleted, or filtered, React reuses the same keys and shows wrong data. Always use a unique id from your data.
