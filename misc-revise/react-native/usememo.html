useMemo

Memoizes a value so it's only re-computed when deps change. Saves CPU on expensive calculations.

Syntax

import { useMemo } from 'react'; const memoized = useMemo(() => { // Expensive calculation here return slowFunction(dep); }, [dep]); // ← only re-runs when dep changes

What it does

  • Stores the result in memory (cache)
  • On re-render, checks if deps changed
  • If deps same → returns cached value instantly
  • If deps changed → re-runs function, stores new result
  • Great for heavy math, filtering, sorting, data transformation
💡 Not free. useMemo itself has overhead (memory + comparison). Use it only for truly expensive computations, not for every variable.

Code (same as the demo)

App.tsx 
function App() {
  const [num, setNum] = useState(30);
  const [theme, setTheme] = useState('dark');

  // ❌ Runs every render — slow!
  const noMemo = slowFib(num);

  // ✅ Runs only when num changes
  const memoized = useMemo(() => {
    return slowFib(num);
  }, [num]);

  // Changing 'theme' re-renders, but useMemo skips re-computation
  return ( <View>...</View> );
}

// Simulated expensive function
function slowFib(n) {
  if (n <= 1) return n;
  return slowFib(n - 1) + slowFib(n - 2);
}
