Rendering Lists

.map() vs FlatList

Two ways to render a list. One is simple but bad for lots of data.

Side by Side

.map() ScrollView 
import { ScrollView } from 'react-native';

<ScrollView>
  {data.map(item => (
    <View key={item.id}>
      <Text>{item.name}</Text>
    </View>
  ))}
</ScrollView>

⚠️ Renders ALL items upfront

❌ No lazy loading

❌ No pull-to-refresh built-in

❌ No scroll-to-index

❌ Bad for 100+ items

✅ Simple & familiar

FlatList Virtualized 
import { FlatList } from 'react-native';

<FlatList
  data={data}
  renderItem={({item}) => (
    <View>
      <Text>{item.name}</Text>
    </View>
  )}
  keyExtractor={item => item.id}
/>

✅ Renders only visible items (lazy)

✅ Built-in pull-to-refresh

✅ scrollToIndex / scrollToOffset

✅ Header / Footer / Separator

✅ Handles 10,000+ items

⚠️ More props to learn

When to use which

Use .map() when
  • You have < 20 items
  • The list never changes size
  • You need a simple layout inside a ScrollView
Use FlatList when
  • You have 20+ items
  • Data comes from an API
  • You need pull-to-refresh
  • You need performance
