Lifecycle Events

Key Concepts

✅ Mount — Screen added to the navigator (first visit). Runs useEffect([],[]).
🔵 Focus — Screen is visible to the user. Runs useFocusEffect.
🔴 Blur — Screen is covered by another screen. Still mounted, but not visible.
⚫ Unmount — Screen removed from navigator (e.g., popToTop from deep stack).

Hooks

// Runs on focus AND on blur (cleanup)
import { useFocusEffect } from '@react-navigation/native';

useFocusEffect(useCallback(() => {
  // Runs when screen comes into focus
  refreshData();
  return () => {
    // Runs when screen loses focus
    stopPolling();
  };
}, []));

// OR: simple boolean
import { useIsFocused } from '@react-navigation/native';
const isFocused = useIsFocused(); // true/false
💡 Key difference: useEffect([],[]) runs once on mount. useFocusEffect runs every time the screen becomes visible. A screen stays mounted when you push another on top — but it loses focus.

Lifecycle Hooks in Action

useFocusEffect 
import { useFocusEffect }
  from '@react-navigation/native';

function HomeScreen() {
  useFocusEffect(
    useCallback(() => {
      // Screen came into focus
      fetchData();

      return () => {
        // Screen left focus
        cleanup();
      };
    }, [])
  );
  return <View>...</View>;
}
useIsFocused 
import { useIsFocused }
  from '@react-navigation/native';

function HomeScreen() {
  const isFocused = useIsFocused();

  // Simple conditional rendering
  if (!isFocused) {
    return <Text>Not focused</Text>;
  }

  // Real-time data polling only when focused
  return <Text>Focused!</Text>;
}
