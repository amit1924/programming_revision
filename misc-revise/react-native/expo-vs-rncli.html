Expo vs CLI Expo

Quick Comparison

Expo Managed workflow, OTA updates, built-in APIs, no native config needed. Best for most apps.
RN CLI Bare workflow, full native control, required for custom native modules. Best for complex native needs.

When to choose what

Expo — You want to ship fast, don't need custom native modules, want OTA updates.
RN CLI — You use native SDKs (Bluetooth, ARKit, custom C++ libs), need full native control.
Expo Dev Client — Best of both: Expo tooling with a custom native build.
💡 Tip: Expo SDK 50+ supports most native modules via Expo Dev Client. Start with Expo; if you hit a native wall, eject to a bare workflow or use a development build.

Commands Side by Side

Expo 
# Create project
npx create-expo-app MyApp
cd MyApp

# Run on device (QR code)
npx expo start
# Scan QR in Expo Go app

# Build for stores (cloud)
npx eas build --platform ios
npx eas build --platform android

# Submit to stores
npx eas submit --platform ios
RN CLI 
# Create project
npx @react-native-community/cli init MyApp
cd MyApp

# Run on simulator/emulator
# (requires Xcode / Android Studio)
npx react-native run-ios
npx react-native run-android

# Build for stores (local)
# Open in Xcode or Android Studio
# Product → Archive (Xcode)
# Build → Generate Signed Bundle (AS)
