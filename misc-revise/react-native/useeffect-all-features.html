useEffect — Mount 
useEffect(() => {
  // Runs once on mount
  console.log('Mounted');
}, []);
// empty deps → only on mount
💡 Tip: Empty deps [] = run once on mount. Never re-runs.

All useEffect Forms

PatternDepsWhen it runs
useEffect(fn)noneEvery render (mount + every update)
useEffect(fn, [])empty✅ Once on mount only
useEffect(fn, [x])[x]On mount + whenever x changes
useEffect(fn, [x, y])[x, y]On mount + when x or y changes

Every Pattern in Code

1. Mount Only 
useEffect(() => {
  fetchData();
}, []); // ← empty deps
2. On Change 
useEffect(() => {
  filterResults(query);
}, [query]); // ← runs when query changes
3. With Cleanup 
useEffect(() => {
  const sub = subscribe();
  return () => unsubscribe(sub);
  // ↑ cleanup runs on unmount + before re-run
}, [sub]);
4. Interval Timer 
useEffect(() => {
  const id = setInterval(tick, 1000);
  return () => clearInterval(id);
  // ← cleanup prevents memory leaks
}, []);
5. No Deps (careful) 
useEffect(() => {
  console.log('Rendered!');
}); // ← no deps = runs EVERY render
Common Mistake
// Forgot deps → infinite loop!
useEffect(() => {
  setCount(count + 1);
}); // ⚠️ no deps → setCount → re-render → loop
