Common Patterns

Image mask
borderRadius + overflow:hidden clips image to rounded shape
Badge overlap
overflow:visible lets badges/indicators spill outside container
Horizontal scroll
overflow:scroll (with horizontal content) creates carousels
⚠️ Platform difference: On iOS, the default overflow is visible. On Android, the default is hidden. Always set it explicitly for cross-platform consistency.

All Overflow Patterns

visible 
<View style={{
  overflow: 'visible'
}}>
  // Children can render
  // outside the container
</View>
hidden 
<View style={{
  overflow: 'hidden',
  borderRadius: 16,
}}>
  // Content clipped
  // to rounded bounds
</View>
scroll 
<View style={{
  overflow: 'scroll'
}}>
  // Overflowing content
  // becomes scrollable
</View>
