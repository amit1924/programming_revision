useRef

Ref = a mutable value that persists across renders without causing re-renders.

Syntax

import { useRef } from 'react'; const myRef = useRef(initialValue); // { current: initialValue } // Read: myRef.current // Write: myRef.current = newValue // ⚠️ Writing does NOT trigger a re-render

useRef vs useState

💡 Rule of thumb: If changing it should show something new on screen → useState. If changing it should NOT show anything new → useRef.

All 4 Use Cases in Code

1. DOM Element 
const inputRef = useRef(null);

// Attach to JSX
<input ref={inputRef} />

// Access DOM node directly
inputRef.current.focus();
inputRef.current.value;
2. Mutable Value 
const countRef = useRef(0);

// Update without re-render
countRef.current += 1;
console.log(countRef.current);

// vs useState — would re-render
const [count, setCount] = useState(0);
3. Previous Value 
const [val, setVal] = useState(0);
const prevRef = useRef(null);

// After render, store current value
useEffect(() => {
  prevRef.current = val;
}, [val]);

// prevRef.current always has the old value
4. Interval / Timer ID 
const timerRef = useRef(null);

const start = () => {
  timerRef.current = setInterval(tick, 1000);
};
const stop = () => {
  clearInterval(timerRef.current);
};

// Cleanup on unmount
useEffect(() => {
  return () => clearInterval(timerRef.current);
}, []);
