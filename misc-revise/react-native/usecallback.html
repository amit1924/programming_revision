useCallback

Memoizes a function reference so it's not recreated every render. Prevents unnecessary child re-renders.

Syntax

import { useCallback } from 'react'; const memoFn = useCallback(() => { doSomething(dep); }, [dep]);

useMemo vs useCallback

useMemouseCallback
Memoizes a valueMemoizes a function
useMemo(() => fn, deps)
useCallback(fn, deps) = useMemo(() => fn, deps)
💡 When to use: When passing callbacks to child components that use React.memo. Without useCallback, the child re-renders every time because it sees a new function reference.

The Code

App.tsx 
function App() {
  const [a, setA] = useState(0);
  const [b, setB] = useState(0);

  // ❌ New function every render
  const handleClickBad = () => setA(a + 1);

  // ✅ Stable reference until 'a' changes
  const handleClickGood = useCallback(() => {
    setA(a + 1);
  }, [a]);

  return (
    <View>
      // Re-renders whenever parent renders (unnecessary)
      <Child onClick={handleClickBad} />

      // Skips re-render if a hasn't changed
      <Child onClick={handleClickGood} />
    </View>
  );
}

// Must be wrapped in React.memo to benefit
const Child = React.memo(({ onClick }) => {
  return <Button title="click" onPress={onClick} />;
});
