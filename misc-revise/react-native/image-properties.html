resizeMode visual

cover — fills box, crops excess
contain — fits entirely, may have bars
stretch — distorts to fill exactly
center — original size, centered
repeat — tiles the image
💡 Tip: Always set width and height on Image. Without them, the image won't render. Use resizeMode to control how it fits.
