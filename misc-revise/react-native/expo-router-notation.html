useLocalSearchParams

import { useLocalSearchParams }
  from 'expo-router';

function UserPage() {
  const { userId } = useLocalSearchParams();
  // userId = "123" for /users/123
  return <Text>User {userId}</Text>;
}
💡 Key insight: The file system IS the navigation tree. Each notation type maps to a navigation pattern — no manual navigator config needed for most cases.

Applied Example

File Tree
src/
  app/
    _layout.tsx        ← root layout (renders first)
    index.tsx            ← / (initial route)
    about.tsx            ← /about (static)
    (home)/              ← route group (no URL prefix)
      _layout.tsx        ← tab layout for (home)
      index.tsx        ← / (default tab)
      feed.tsx         ← /feed
      profile.tsx      ← /profile
    [username]/                   ← dynamic segment
      index.tsx        ← /:username
      settings.tsx     ← /:username/settings
    +not-found.tsx              ← 404 catch-all
URL Mapping
  /          → (home)/index.tsx
  /about     → about.tsx
  /feed      → (home)/feed.tsx
  /profile   → (home)/profile.tsx
  /evanbacon → [username]/index.tsx
              (username="evanbacon")
  /evanbacon/settings
             → [username]/settings.tsx
              (username="evanbacon")
  /unknown   → +not-found.tsx
