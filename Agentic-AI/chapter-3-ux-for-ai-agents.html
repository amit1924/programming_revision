UX for AI Agents

Designing the experience around the brain — because a brilliant model behind a terrible interface still produces a terrible product.

1

What is Agent UX? ❤️

"What is it like for a person to use this AI?"

🤖

Agent A — Bad UX

Doesn't explain capabilities
Confusing errors
Forgets conversation
Dangerous actions without warning
🤖

Agent B — Good UX

Clearly explains capabilities
Remembers context
Handles errors properly
Asks before important actions

UX affects effectiveness, trust, and adoption.

2

Interaction Modalities 📱

A modality = how the user communicates with the agent.

📝

Text

"Cancel my order A123"
"Done. Your order was cancelled."
Simple Searchable Easy to save Sync + Async
🖥️

GUI

🤖 Customer Support
📦 Track Order
❌ Cancel Order
🔄 Return Product
👤 Talk to Human
Visual controls Guided choices No guessing
🎙️

Voice

"Call Mom."
"Calling Mom."
Hands-free 🚗 Driving 🍳 Cooking 🏠 Smart home
🎥

Video

AI Avatar visually explains something
Visual demonstration 🎓 Virtual tutors Rich expression

Which Modality?

Simple + searchable? → 📝 Text
Visual controls? → 🖥️ GUI
Hands-free? → 🎙️ Voice
Visual demo? → 🎥 Video

Combine them? That's multimodal interaction.

3

Context Management 💾

Without Context 😵

"My order number is A123."
"Okay."
"What's its status?"
"Which order?"
😑

With Context 😊

"My order number is A123."
"Got it."
"What's its status?"
"Order A123 is out for delivery."
😊

Where Does Context Come From?

📝 Conversation
Messages in current chat
💻 App Context
Cursor auto-detects your files
🧠 Memory
Preferences across sessions

Memory Across Sessions

📅 Monday:
"I prefer concise explanations."
📅 Friday:
"Explain LangGraph."
Agent gives concise explanation ✅
4

Communicating Limitations ⚠️

The user needs to know: What can this agent actually do?

Can do

✅ Track orders
✅ Cancel orders
✅ Update addresses

Cannot do

❌ Change product price
❌ Issue special discounts
❌ Modify payment info

Without disclosure:

"Give me a 90% discount."
"I can't do that."
😡

With disclosure:

"I can help you track, cancel, or update account details. I can't change prices."
User understands capabilities upfront

What About Uncertainty?

"I'm not completely certain, but based on the available information, I think..."
🤖 Certain 🤖 Probably 🤖 Uncertain

Being honest about confidence builds trust.

5

Trust & Transparency 🤝

Trust comes from: predictable behavior, clear explanations, understanding what the agent did.

Agent deletes a file:
"Done."
User: "WHAT DID YOU DELETE?! 😨"
Transparent agent:
"I deleted /project/test.js because you asked me to remove the unused test file."
User: "Perfect. Thanks."

7

Discoverability 👁️

Discoverability = Can the user easily discover what the system can do?

Text's Weakness

"How can I help?"
🤔 "What can you actually do?"

Fix: Tell the User

"I can help you:
• Cancel orders
• Track deliveries
• Update account details
• Check refunds"

Better AI CLI

$ ai

I can help you:
🔍 Search files
🐳 Manage Docker
☸️ Inspect Kubernetes
🧪 Run tests
💻 Explain code

What would you like to do?

Recommendations: onboarding messages, capability reminders, dynamic suggestions.

8

Conversation Quality 💬

Keep Responses Clear

Bad:
"The requested operation has encountered a downstream infrastructural exception."
😵 What?
Good:
"I couldn't connect to the payment service. Please try again."

Maintain Context

Bad:
"Cancel it."
"Which order?" 😑
Good:
"Cancel it."
"Order A123 has been cancelled."

Agent understands "it" = A123.

Turn-Taking

Right amount:
"Cancel order A123" → Cancelled. Done.
Too many questions:
"Are you sure?" → "Would you like me to?" → "Should I proceed?" 😡

Confirmation depends on risk level.

Handle Ambiguity

"Cancel that one."
"Do you mean order A123 or B456?"

Don't guess — ask.

Response Length — The Sweet Spot

Too Short
"Done."
Not enough info
Just Right ✅
"Order A123 cancelled. Refund ₹2,499 in 3-5 days."
Clear + useful
Too Long
"Let me provide a comprehensive 17-paragraph explanation..."
😭

Text Lacks Emotional Information

"I'm fine."
😊 "I'm fine!" 😡 "I'm fine." 😢 "I'm fine..."

Text agents must carry empathy through words alone.

9

Good Error Handling 💥

Bad:

"Error 500"
😐 What am I supposed to do with that?

Good:

"I couldn't access the order system right now.
You can:
1. Try again
2. Contact support"
10

Putting It All Together 🤖

AI DevOps Assistant — good UX in action:

"My Docker container keeps crashing. Find out why."
Agent works...
🔧 docker ps 🔧 docker logs 🔧 inspect
"The container is restarting because the Node process exits with error X."
"Your app is trying to connect to MongoDB using localhost, but MongoDB is running in another container.

I can show you how to fix the connection. Would you like me to?"
✅ Understands context ✅ Explains what happened ✅ No technical garbage ✅ Honest about limits ✅ Offers next steps
⭐

7 Things to Remember 🏆

📝

1. Modality

How does the user interact? Text / GUI / Voice / Video

💾

2. Context

The agent needs relevant information.

🧠

3. Memory

Remember useful information across interactions.

👀

4. Discoverability

Users should know what the agent can do.

🛡️

5. Transparency

Understand actions and limitations.

💥

6. Error Handling

When something fails, explain and offer a path forward.

💬

7. Conversation Quality

Context, ambiguity, turn-taking, not overwhelming users.

The Big Lesson

Don't design only the AI brain. Design the experience around the brain.

A brilliant model behind a terrible interface still produces a terrible product.

Architecture and models provide capability, but how people interact with the agent determines whether they trust and adopt it.
