4

🔌 MCP Tools

Model Context Protocol (MCP)

A standardized way for AI systems to interact with external capabilities and context.

Without a standard:
🤖 AI → Custom API → Custom code → Custom integration
Each one is different 😵
With MCP:
🤖 AI → 🔌 MCP → Files | Data | Tools
Standard interface ✅

MCP can provide:

User info Conversation history External knowledge Current state Task-specific info

Just remember: MCP = standardized way for AI to connect with external context/capabilities.

Good Architecture

MEMORY
6

Memory 💾

Memory allows agents to store, retrieve, maintain context, learn from interactions, and improve decisions over time.

🟢

Short-Term Memory

Remember what is happening right now.

Message 1:"My name is Amit."
💾 Short-term memory stores it
Message 2:"What is my name?"
🤖 "Your name is Amit."

Maintains context during the current conversation/task.

🔵

Long-Term Memory

Remember something across future interactions.

Today:"I prefer simple code examples."
💾 Database stores preference
Next week:Agent remembers preference
🤖 Responds accordingly ✅

Uses databases, knowledge graphs, or fine-tuning.

🟢 Short-Term 🔵 Long-Term
Purpose Current task Future tasks
Duration Short Long
Storage Context/messages Database/knowledge store

Rolling Context Window

Agent remembers only the latest N messages:

Msg 1 Msg 2 Msg 5 Msg 6 Msg 7 Msg 8
As new messages arrive, old ones slide out:
[1,2,3,4] → [2,3,4,5] → [3,4,5,6] → [4,5,6,7]

Memory ≠ Remember Everything

Wrong approach:
100 purchase records → 😵
Right approach:
Recent + relevant → ✅

Memory needs to distinguish relevant vs irrelevant info and sometimes forget outdated information.

The logic that composes, schedules, and supervises multiple skills/actions so they work toward a goal.

8

Design Trade-offs ⚖️

⚡ Fast 🎯 Accurate 💰 Cheap 📈 Scalable 🛡️ Reliable

Improving one can hurt another. That's engineering.

⚡ Model A

Response: 0.5 seconds
Accuracy: 85%

Good for: autonomous driving (speed critical)

🧠 Model B

Response: 8 seconds
Accuracy: 98%

Good for: legal analysis (accuracy critical)

Hybrid Approach: Fast First, Accurate Later

User asks question
🤏 Small model → Quick recommendation
🧠 Large model → Verify
✅ Final answer

Reliability 🛡️

Fault Tolerance

Bad: 💥 Crash
API fails → Agent dies
Resilient:
API fails → Retry → Fallback → 👤 Human

Testing — You Must Test All Cases

Normal input ✅ Wrong input ✅ Empty input ✅ Unexpected ✅ API failure ✅ Tool failure ✅ Huge workload ✅ Malicious ✅
You shouldn't only test divide(10, 2). You should also test divide(10, 0) — because 💥.

Cost vs Value

👍 Worth it
Saves ₹10 lakh/month · Costs ₹1 lakh/month
😬 Not worth it
Saves ₹5,000/month · Costs ₹50,000/month

The cost of the agent should be justified by the value it creates.
