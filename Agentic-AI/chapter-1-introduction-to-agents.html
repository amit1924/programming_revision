NOT an Agent

Just a single LLM call. No decision-making.

NOT an Agent

Step 1 → Step 2 → Step 3 → Step 4

Fixed sequence = workflow, not agent.

Foundation Models Changed the Game 🧠

The evolution is driven by three forces:

Foundation Models Reinforcement Learning Tool/Function Calling

Tool Calling — The Fundamental Building Block

OLD WAY — No Tool Calling
Input: "What is the weather?"
Output: "I don't know the current weather."

Model can only generate text.

NEW WAY — Tool Calling
LLM produces structured call:
{
"tool": "get_weather",
"arguments": {"city": "Patna"}
}
User "What's the weather?"
LLM "I need weather info"
get_weather("Patna")
Weather API → 40°C
LLM "Patna is currently 40°C..."

17

7 Key Ideas to Remember ⭐

1

An LLM is not automatically an agent

Simply calling an LLM does not make something an agent. There must be autonomy.

2

An agent has some ability to decide what to do next

Decision-making is the core differentiator between scripts and agents.

3

Agency exists on a spectrum

From simple scripts to fully autonomous agents — it's not binary.

4

Tool calling is a fundamental capability

Modern agents are built on the ability to call external tools via structured outputs.

5

An agentic system is much bigger than the LLM

Tools, memory, planning, orchestration, security — all surround the model.

6

RAG, memory, tools, planning are components — not synonyms

RAG is a component inside an agent, not the agent itself.

7

The real challenge is production reliability

Making an agent work once is easy. Making it reliable in production is the hard part.
