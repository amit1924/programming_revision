Combining Interfaces & Advanced UX

Modality fluidity, autonomy, sync vs async, personalization, failure handling, and trust — the 8 rules that make agents truly usable.

1

Modality Fluidity 🔄

Users don't care about "modalities." They care about getting the job done.

Same Task, Different Modalities

🚗
Driving
"Hey AI, remind me what meetings I have today."
🎙️ Voice
💻
At work
"Here are today's meetings..."
🖥️ GUI
📱
In meeting
"Summarize the meeting preparation."
📝 Text

Same context continues across all modalities.

2

State Management 💾

Bad System

"Find me a flight to Delhi tomorrow."
"Sure. What time?"
📱 Phone dies...
"Hello! How can I help?"
😂 "BRO WE WERE TALKING ABOUT THE FLIGHT!"

Good System

"Find me a flight to Delhi tomorrow."
"What time?"
📱 Switch to laptop...
"You were looking for a flight to Delhi tomorrow. You hadn't selected a departure time yet."
✅ Context persists!

Information, task progress, and user preferences shouldn't disappear when switching modalities.

Synchronous — Immediate

"4"

"Analyze this 5,000-page doc"
👤 Go do something else...
🔔 "Report completed!"
📧 Email 📊 Reports 🔍 Deep research

Good Async UX — Progress Updates

Bad: Staring at spinner
⏳ 😐
15 minutes with no feedback
Good: Progress updates
🔍 Security analysis started
Checked: ✅ Auth ✅ Dependencies 🔄 API
🔔 We'll notify you when complete

Proactive Behavior 🔔

Useful Proactive

"Your server is down."

Genuinely useful. 👍

Intrusive Agent 😭

"Your server is down."
"Your server is down."
"Your server is down."

User: "STOP PINGING ME!"

Proactive behavior should be context-aware, genuinely useful, and user-controlled (frequency, channels, thresholds).

8

Uncertainty & Asking 🤔

Bad: Overconfident

"Definitely! This is 100% correct."

...when it's not sure 😱

Bad: Over-hedging

"Maybe 2+2 could possibly be 4, but I'm not completely certain..."

😂 Feels incompetent

Right Balance

"I'm not fully certain. The available evidence suggests X, but I'd recommend verifying Y."
High confidence → Direct Low confidence → Caveat

Ask Instead of Guessing

"Book me a ticket to Chicago."
Missing info:
One-way or round? Which date? Which airport?
Bad: Interrogation
"Please provide date, time, airport, airline, seat, baggage, meal, loyalty number..."
😵
Good: Focused questions
"Sure. What date, and one-way or round-trip?"

Sequence questions logically.

9

Graceful Failure 💥

"A good agent isn't one that never fails. It's one that fails well."

Bad: Error 500
Useless message
Worse: False success
"Payment successful!"
(it wasn't) 😱
Good: Graceful
"Payment unavailable. Not charged. Try again / Save / Support"

Preserve Progress

Bad: Restart everything
Step 1 ❌ Start again...
Good: Resume from failure
Step 1 ✅ Step 2 ✅ Step 3 ❌ → Retry step 3
10

Trust 🤝

"Trust is gained in drops and lost in buckets."

99 things right ✅✅✅...

Trust builds slowly.

1 thing wrong: 💀

"I deleted your production database."

Trust gone.

Trust = Transparency + Predictability + Reliability + Good failure handling

Transparency ≠ showing everything. Users need enough info to understand what's happening.

⭐

8 Rules to Remember 🏆

1️⃣

Goals, Not Modalities

Users care about getting the job done. Use text/voice/GUI as needed.

2️⃣

Control Over Autonomy

Manual → Assist → Autonomous. Let users choose.

3️⃣

Sync for Immediate Tasks

Chat, voice, live interaction. Request → immediate response.

4️⃣

Async for Long-Running Work

Research, reports, background tasks. Start → return later.

5️⃣

Remember Context

Short-term + Long-term memory. Don't forget what was said.

6️⃣

Expose Capabilities

Don't make users guess. Suggest, show buttons, onboarding.

7️⃣

When Uncertain, Ask

Don't guess. Ask focused, sequenced clarification questions.

8️⃣

Fail Gracefully

Explain → Preserve state → Offer next step.

Underneath Everything

Build trust through predictable, transparent, reliable behavior.
