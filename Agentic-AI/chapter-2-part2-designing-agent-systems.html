Creating a Tool 🔧

It's just a Python function

@tool
def cancel_order(order_id: str) -> str:
return f"Order {order_id} has been cancelled."

The @tool decorator tells the framework this function is available to the LLM.

Why call it a "tool"?

LLM
"I need to cancel order A12345"
cancel_order()
"Order A12345 has been cancelled."

The LLM calls this function — just like a tool.

Real vs Learning

For learning:
return f"Order {id}
cancelled."
Simple fake function ✅
In production:
response = requests.post(
  "api.myshop.com/cancel"
  json={"id": id}
)
Real API call

Fake function lets you understand the concept without API complexity.

The Agent Brain — Two LLM Calls 🧠

The System Prompt

You are an ecommerce support agent.
ORDER ID: A12345
If the customer asks to cancel,
call cancel_order(order_id).
Then send a simple confirmation.

We're telling the LLM: "Here is your job and the tool you can use."

1

First LLM Call — DECIDE

"Please cancel A12345"
LLM
"Which tool should I use?"
🔧 cancel_order
order_id = A12345

Pattern: LLM → Tool

2

Second LLM Call — RESPOND

"Please cancel A12345"
Tool: "Order A12345 has been cancelled."
LLM
"What should I tell the customer?"
"Your order A12345 has been cancelled."

Pattern: Tool result → LLM → Response

Call 1 → 🧠 Decide   |   Call 2 → 🗣️ Respond

7

Evaluation 🧪

Key Point

"Look! My agent works!" because it worked once. That's not enough.

Three Evaluation Questions

1
Did the agent choose the correct tool?
cancel_order · refund
2
Did it use the correct order ID?
B73973 · B79373
3
Did it give the correct confirmation?
"Your order B73973 has been cancelled."

Test Passes

result = "cancel_order"
assert "cancel_order" in result
# ✅ Passes

Test Fails

result = "refund"
assert "cancel_order" in result
# ❌ Fails

"An untested agent is an untrusted agent."

LLMs are probabilistic — same input can produce different outputs. You need evaluation.

Model Selection for Agents 🧠

🧠 Large Model

Complex tasks
Better reasoning
More expensive
Higher latency

🤏 Small Model

Simple tasks
Faster
Cheaper
Lower latency

Our E-Commerce Agent

The job is relatively simple:

Understand "cancel" Extract order ID Call tool Confirm

A small fast model may be sufficient! 🤏

Don't Assume Expensive = Better

Model A
Cost: ₹1
Accuracy: 90%
Model B
Cost: ₹5
Accuracy: 94%
Model C
Cost: ₹20
Accuracy: 95%

Extra 4% accuracy may not justify 20× cost.

Model A might be perfectly good.
