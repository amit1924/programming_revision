Course Curriculum

01

Cloud Computing

What the cloud really is, on-prem vs cloud, the 3 service models (IaaS/PaaS/SaaS), global infrastructure, and why you should care.

Completed 02

Networking — VPC

Virtual Private Clouds, subnets, route tables, internet gateways, security groups, and NACLs — how AWS networks talk to the world.

Completed 03

EC2 — Elastic Compute

Virtual machines in the cloud: instances, AMIs, instance types, key pairs, security groups, user data scripts, and pricing models.

Completed 04

RDS — Databases

Managed relational databases: PostgreSQL, MySQL, Aurora; multi-AZ, read replicas, backups, and connecting from your apps.

Completed 05

IAM — Identity & Access

Users, groups, roles, policies, and the shared responsibility model. The single most important AWS security concept you must learn.

Completed 06

Monitoring — CloudWatch

Metrics, alarms, logs, dashboards, and CloudTrail. How to know your infrastructure is healthy before users do.

Completed 07

DNS — Route 53

How domain names work, DNS record types, hosted zones, routing policies (simple, weighted, latency, failover), and health checks.

Completed 08

S3 — Object Storage

Buckets, objects, keys, storage classes, versioning, lifecycle rules, static website hosting, and durability guarantees.

Completed 09

CDN — CloudFront

Content Delivery Networks, edge locations, origins, distributions, cache behaviors, and why the internet feels fast.

Completed 10

ECS — Containers

Docker containers on AWS: task definitions, services, clusters, Fargate vs EC2 launch types, and running real containers.

Completed 11

Lambda — Serverless

Run code with zero servers. Functions, triggers, event-driven architecture, cold starts, and the serverless mindset.

Completed

Capstone — Ship www.amit.com

The finale: put it all together — S3 site + Lambda API + ECS web tier + Route 53 DNS + CloudFront CDN, observed in CloudWatch. Verified live on Floci.
