gsap.utils — Utility Functions

gsap.utils provides functional helpers — pipe, distribute, selector, mapRange, and more. These are pure functions you use outside of GSAP tweens to compose logic.

1

pipe() — Function Composition

pipe
// pipe(value, fns...) passes a value through each function left-to-right. // Each function receives the return value of the previous one. const add2 = x => x + 2; const double = x => x * 2; const square = x => x * x; const transform = gsap.utils.pipe(add2, double, square); console.log(transform(3)); // ((3+2)*2)^2 = 100 // Equivalent to: square(double(add2(3)))

Enter a number and see it pass through the pipeline:

→ add2 → double → square
> transform(3) = 100

pipe is useful for chaining calculations, e.g., mapping mouse position → normalized → clamped → applied to a tween.

selector() — Scoped DOM Queries

selector
// selector() creates a scoped querySelectorAll bound to a parent element. // Perfect for targeting elements inside a specific container. const container = document.querySelector("#scopeDemo"); const q = gsap.utils.selector(container); // q(".item") → only .item children of #scopeDemo gsap.to(q(".item"), { x: 80, stagger: 0.15 }); // Without selector: document.querySelectorAll("#scopeDemo .item")

mapRange() — Remap Values

mapRange
// mapRange(inMin, inMax, outMin, outMax, value) // Maps a value from one numeric range to another. const mouseToHue = gsap.utils.mapRange(0, 800, 0, 360); console.log(mouseToHue(400)); // 180 console.log(mouseToHue(200)); // 90 // Also: mapRange(inMin, inMax, outMin, outMax) → returns a reusable function // Or: mapRange(inMin, inMax, outMin, outMax, value) → returns the mapped value

Bonus: clamp, snap, random, interpolate

clamp snap random interpolate
// clamp(min, max, value) — constrain within range gsap.utils.clamp(0, 100, 150); // 100 // snap(increment, value) — snap to nearest increment gsap.utils.snap(15, 22); // 15 // random(min, max, increment) — random in range gsap.utils.random(0, 100, 5); // e.g. 35 // interpolate(from, to, progress) — linear interpolation gsap.utils.interpolate(0, 100, 0.5); // 50

Putting It All Together

pipe distribute mapRange clamp
// A real-world example combining utils: const boxes = gsap.utils.selector(document.getElementById("comboDemo")); // Distribute initial x positions const pos = gsap.utils.distribute({ amount: 200, base: 20, from: "start" }); const hues = gsap.utils.distribute({ amount: 300, base: 0, from: "start" }); boxes(".combo-item").forEach((el, i) => { gsap.set(el, { x: pos(i), backgroundColor: `hsl(${hues(i)}, 80%, 60%)` }); });

Key Takeaways — gsap.utils

pipe(value, ...fns) — Chain functions left-to-right. Each output feeds the next input.
distribute({amount, base, from, ease, grid}) — Returns (index) => value. Great for stagger positions.
selector(parent) — Returns (selector) => elements[] scoped to parent. Replaces parent.querySelectorAll.
mapRange(inMin, inMax, outMin, outMax) — Returns a reusable function to remap values across ranges.
clamp(min, max) — Constrains a value within a range.
snap(increment) — Snaps to nearest increment.
random(min, max, increment?) — Random value in range.
interpolate(from, to, progress) — Linear interpolation between values.
