Timeline — Sequencing Animations

Chapters 1-3 taught you single animations. Now chain them together in perfect sequence with GSAP's built-in timeline.

1 The Problem — Chaining Without Timeline

Before timelines, developers chained animations using onComplete callbacks. It works, but creates deeply nested "callback hell" — hard to read, hard to reorder, hard to maintain.

❌ Callback Hell 
gsap.to(".box", {
  x: 200,
  onComplete: () => {
    gsap.to(".box", {
      rotation: 180,
      onComplete: () => {
        gsap.to(".box", {
          scale: 0.5
        });
      }
    });
  }
});
// 😵 Hard to read, reorder, or debug
✅ Timeline 
const tl = gsap.timeline();

tl.to(".box", { x: 200 })
  .to(".box", { rotation: 180 })
  .to(".box", { scale: 0.5 });

// ✅ Chainable, readable, easy to reorder
// Each .to() runs AFTER the previous one finishes
chain

Both demos do the exact same thing: move right → rotate 180° → scale down. The timeline version is 5 lines vs 15 — and you can reorder steps by just moving a line.

2 Creating a Timeline

Create a timeline with gsap.timeline(), then chain .to(), .from(), and .fromTo() onto it. 

// 1. Create the timeline
const tl = gsap.timeline({
  defaults: {
    duration: 0.6,
    ease: "power2.out"
  }
});

// 2. Chain tweens — they run one after another
tl.to(".box", { x: 150 })  // 0s → 0.6s
  .to(".box", { rotation: 90 }) // 0.6s → 1.2s
  .to(".box", { scale: 0.3 }); // 1.2s → 1.8s

defaults is a game-changer. Set duration and ease once in the timeline constructor, and every chained tween inherits them. Override per-tween when needed.

3 The Position Parameter

Every chained method accepts an optional position parameter as the 3rd argument — it controls when the tween starts. This is the most powerful timeline feature. 

// Absolute time (seconds)
tl.to(box, { x: 200 }, 0.5)
  // starts at 0.5s regardless of other tweens

// Relative to end (+=)
tl.to(box, { x: 200 })
  .to(box, { rotation: 90 }, "-=0.3")
  // starts 0.3s BEFORE previous tween ends

// Relative to start (-= on timeline)
tl.to(box, { x: 200 })
  .to(box, { scale: 0.5 }, "+=0.2")
  // starts 0.2s AFTER previous tween ends

// Label reference
tl.addLabel("middle", 1.5)
  .to(box, { rotation: 90 }, "middle")
  // starts at the "middle" label

// "<" means "at the START of the previous tween"
tl.to(box, { x: 200 }, "<")
  .to(box, { y: 100 }, "<")
  // both start at the same time!

4 Stagger in a Timeline

Combine timeline with stagger for complex group sequences — like rows of items entering one by one, then doing something together. 

// Timeline with stagger + position parameter
const tl = gsap.timeline({ defaults: { duration: 0.4, ease: "back.out(1.7)" } });

// Row 1: stagger fly in (each takes 0.4s + 0.1s stagger = 0.8s total)
tl.from(".row1 .item", {
  y: -40, opacity: 0,
  stagger: 0.12
});

// Row 2: starts when row 1's stagger is done
tl.from(".row2 .item", {
  x: -40, opacity: 0,
  stagger: 0.12
}, "-=0.3");
// Overlap: row2 starts 0.3s before row1 finishes!

6 Timeline Controls

Timelines have built-in methods to play, pause, reverse, restart, and even seek to a specific time. 

const tl = gsap.timeline();

tl.to(".box", { x: 200, duration: 1 })
  .to(".box", { rotation: 180, duration: 1 })
  .to(".box", { scale: 0.3, duration: 1 });

// Controls:
tl.play();      // ▶ play forward
tl.pause();     ">|| pause at current position
tl.reverse();   > ◀ play backward
tl.restart();   > ↺ go to 0 and play
tl.progress(0.5); > jump to 50%
tl.seek(1.5);   > jump to 1.5s
tl.timeScale(2); > play at 2x speed

Progress
Speed

timeScale() is the hidden gem — speed up playback for testing without changing durations. At 4x, a 3-second sequence plays in 0.75s.
