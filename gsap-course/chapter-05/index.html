ScrollTrigger — Scroll-Powered Animations

Chapters 1-4 were time-based. Now learn ScrollTrigger — animations that fire based on where the user has scrolled. This is how modern landing pages create those stunning scroll-driven reveals.

1 What is ScrollTrigger?

ScrollTrigger is a GSAP plugin that links animations to the scroll position of a container. Instead of playing on a timeline, animations play as the user scrolls.

❌ Before 
// Animation plays immediately or on click
gsap.to(".box", {
  x: 300, duration: 1
});
// No connection to scroll position
✅ With ScrollTrigger 
gsap.to(".box", {
  x: 300,
  scrollTrigger: {
    trigger: ".box",
    start: "top center",
    end: "top 100px",
    scrub: true
  }
});
// Animation plays as user scrolls past the box

Important: ScrollTrigger is a separate plugin. You must include it: src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/ScrollTrigger.min.js"

2 Trigger, Start & End

Three essential properties: trigger (which element), start (when to begin), and end (when to finish). Use markers: true to visualize them during development. 

gsap.to(".box", {
  x: 250,
  scrollTrigger: {
    trigger: ".box",
    start: "top center",
    end: "top 200px",
    markers: true,
    scrub: 1
  }
});

// "top center" = trigger's top hits viewport center
// "top 200px"  = trigger's top is 200px from viewport top
// markers show colored lines for debugging
↓ Scroll down to see me animate

Format

"{triggerPos} {viewportPos}"

e.g. "top center", "bottom 80%", "left 200px"

Trigger positions

top, bottom, center, left, right

Viewport positions

top, center, bottom, 80%, 200px

Pro tip: Always add markers: true when developing. You'll see exactly where your triggers fire — then remove it before going live.

3 Toggle Actions

toggleActions controls what happens at each scroll boundary. It takes 4 space-separated values: onEnter onLeave onEnterBack onLeaveBack. 

gsap.to(".box", {
  x: 250,
  scrollTrigger: {
    trigger: ".box",
    start: "top center",
    end: "bottom center",
    toggleActions: "play none none reverse"
  }
});

// Values for each action:
• play  → play forward
• pause → pause at current
• resume → continue playing
• reverse → play backward
• restart → go to 0 then play
• none → do nothing
• complete → jump to end

// Most common patterns:
"play none none none"    // play once (default)
"play none none reverse" // play, reverse on scroll up
"play pause resume reset" // complex interaction
↓ Scroll — plays on enter, reverses on leave back

onEnter

Scrolling down, enters trigger

onLeave

Scrolling down, leaves trigger

onEnterBack

Scrolling up, re-enters trigger

onLeaveBack

Scrolling up, leaves trigger

4 Scrub — Direct Scroll Mapping

scrub: true links the animation progress directly to the scroll position. No "play" — the animation follows your finger exactly. 

// Without scrub: animation plays once when trigger hits
// With scrub: animation follows scroll in BOTH directions

gsap.to(".box", {
  x: 300,
  rotation: 180,
  scrollTrigger: {
    trigger: ".box",
    start: "top bottom",
    end: "top 100px",
    scrub: 1
    // 1 = 1 second of smoothing
    // true = instant follow
  }
});
scrub

scrub: true

Animation position = scroll position. Instant. No lag.

scrub: 0.5–3

Adds smoothing (in seconds). The animation "catches up" to scroll — feels buttery.

5 Pin — Lock Elements in Place

pin: true locks the trigger element in place while the rest of the page scrolls past. Perfect for section headers or sticky reveals. 

gsap.to(".section", {
  scrollTrigger: {
    trigger: ".section",
    start: "top top",
    end: "bottom top",
    pin: true,
    scrub: true
  }
});

// The element is "pinned" in the viewport
// from start to end, while content scrolls behind it
// GSAP adds a pin-spacer div automatically
↓ Scroll — I'll pin in place

pin: true

Pins the trigger element itself

pin: ".selector"

Pin a different element by selector

pinSpacing: true

Adds padding to prevent layout jump (default: true)

6 Practical: Scroll Reveal Sections

The most common ScrollTrigger pattern — elements fade and slide in as they enter the viewport. Each .reveal-item gets its own trigger. 

// One function to reveal everything
function revealOnScroll() {
  gsap.from(".reveal-item", {
    y: 40,
    opacity: 0,
    duration: 0.8,
    stagger: 0.15,
    scrollTrigger: {
      trigger: ".reveal-item",
      start: "top 85%",
      toggleActions: "play none none none"
    }
  });
}

// Each item animates independently
// when it reaches 85% from viewport top
// stagger: 0.15 adds delay between each
Section 1 — Hero comes into view
Section 2 — Features slide up
Section 3 — Stats fade in
Section 4 — Testimonials stagger
Section 5 — CTA bounces in

Real-world usage: This exact pattern is used on Apple, Stripe, and Airbnb landing pages. Each element reveals independently as it scrolls into view. Pair with stagger for lists, scrub for parallax.
