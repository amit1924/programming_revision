Text Animations — Characters, Words & Typewriter

Text is the most common element on any page. Learn to animate it letter by letter, word by word, and with typewriter effects.

1 The Challenge with Text

You can't animate individual letters in a <p> tag because it's one DOM element. To animate per-character or per-word, you need to split the text into individual <span> elements first.

Before
<!-- One element, one animation -->
<h2>Hello World</h2>

// Can only animate the whole thing
gsap.from("h2", { opacity: 0 });
// Whole text fades in at once
After split
<!-- Each letter is a span -->
<h2>
  <span>H</span><span>e</span>
  <span>l</span><span>l</span><span>o</span>
  ...
</h2>

// Animate each letter!
gsap.from("h2 span", {
  opacity: 0,
  y: -20,
  stagger: 0.05
});

Key insight: GSAP has no built-in text splitter (unlike libraries like SplitText). We'll write a simple JS helper to split text into characters or words manually.

2 Text Split Helper

A reusable function that takes an element, splits its text into chars or words, wraps each in a <span>, and returns the array for GSAP to animate. 

// Split into characters
function splitChars(el) {
  const text = el.textContent;
  el.textContent = '';
  const chars = [...text].map(char => {
    const span = document.createElement('span');
    span.className = 'char';
    span.textContent = char === ' ' ? '\u00A0' : char;
    el.appendChild(span);
    return span;
  });
  return chars;
}

// Split into words
function splitWords(el) {
  const text = el.textContent;
  el.textContent = '';
  const words = text.split(' ').map(word => {
    const span = document.createElement('span');
    span.className = 'word';
    span.textContent = word;
    el.appendChild(span);
    el.append(' '); // preserve space
    return span;
  });
  return words;
}

Split Me!

The helper handles spaces (non-breaking space for chars, text node for words) so layout stays correct. Each span gets a class for easy GSAP targeting.

3 Character Animation

Once text is split into .char spans, GSAP can animate each letter with stagger — creating that satisfying "unfolding" effect. 

// Step 1: Split
const chars = splitChars(el);

// Step 2: Set initial state
gsap.set(chars, {
  opacity: 0,
  y: -30,
  rotationX: -90
});

// Step 3: Animate in with stagger
gsap.to(chars, {
  opacity: 1,
  y: 0,
  rotationX: 0,
  duration: 0.5,
  stagger: 0.04,
  ease: "back.out(1.7)"
});

Animate

stagger: 0.04

Each letter starts 40ms after the last — creates a smooth wave

rotationX

3D rotation on X axis — letters flip into view

back.out(1.7)

Slight overshoot at the end — letters "pop" into place

4 Word Animation

Word-by-word is more readable for longer text. Split into .word spans and use a larger stagger. 

// Split into words
const words = splitWords(el);

// Animate each word sliding in
gsap.from(words, {
  opacity: 0,
  x: -40,
  duration: 0.6,
  stagger: 0.12,
  ease: "power2.out"
});

// stagger: 0.12 = 120ms between each word
// 6 words × 0.12 = 0.72s total animation

Words slide in one at a time

Characters vs Words: Characters are great for titles and short phrases. Words work better for paragraphs and longer text where per-letter is too slow or hard to read.

5 Typewriter Effect

The classic typewriter reveals characters one at a time with a blinking cursor. With GSAP, we use a timeline with stagger and a CSS cursor. 

// 1. Split into chars, set all invisible
const chars = splitChars(el);
gsap.set(chars, { opacity: 0 });

// 2. Reveal one by one with stagger
gsap.to(chars, {
  opacity: 1,
  duration: 0.05,
  stagger: 0.06,
  ease: "none"
});

// 3. Add blinking cursor with CSS
// .typing-text::after { content:'|'; }
// @keyframes blink { 50% { opacity:0; } }

Typewriter!

stagger: 0.06

60ms per character = ~16 chars/second (comfortable reading speed)

duration: 0.05

Each character fades in very fast — looks like instant appearance

CSS cursor

Blinking "|" via ::after pseudo-element animation

6 Fancy Combined Reveals

Combine multiple properties for impressive text reveals — fade + slide + scale + color. Each character transitions through multiple states. 

// Multi-property character reveal
gsap.from(chars, {
  opacity: 0,
  scale: 2,
  rotation: -30,
  y: -40,
  duration: 0.6,
  stagger: 0.05,
  ease: "back.out(1.7)",
  onComplete: () => {
    // BONUS: randomize colors after reveal
    chars.forEach(c => {
      c.style.color = randomColor();
    });
  }
});

Fancy

Experiment: After the stagger animation completes, each character gets a random color from the gradient palette — creating a rainbow title effect. Combine this with scrollTrigger for scroll-driven text reveals.
