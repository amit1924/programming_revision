gsap.effects — Reusable Animation Recipes

gsap.registerEffect() lets you package any animation logic into a reusable named effect with defaults — invoke it with gsap.effect("name", target, config) or extend it directly onto timelines.

1

registerEffect — Your First Effect

registerEffect defaults
// registerEffect defines a named, reusable animation recipe. gsap.registerEffect({ name: "fadeIn", effect: (targets, config) => { return gsap.fromTo(targets, { opacity: 0, y: 20 }, { opacity: 1, y: 0, duration: config.duration, ease: config.ease } ); }, defaults: { duration: 0.6, ease: "power2.out" } }); // Usage: gsap.effect("fadeIn", ".el"); gsap.effect("fadeIn", ".el", { duration: 1, ease: "bounce.out" });

extendTimeline — Chain Effects on Timelines

extendTimeline Timeline
// With extendTimeline: true, the effect becomes a method on any timeline. gsap.registerEffect({ name: "slideIn", effect: (targets, config) => { return gsap.fromTo(targets, { x: -config.distance || -100, opacity: 0 }, { x: 0, opacity: 1, duration: config.duration, ease: config.ease } ); }, defaults: { duration: 0.5, distance: 80, ease: "power2.out" }, extendTimeline: true // ← Key! Enables tl.slideIn() }); // Usage on timeline: const tl = gsap.timeline(); tl.slideIn(".el1").slideIn(".el2", { distance: -80 }).slideIn(".el3", { duration: 1 });

Parameterized Effects — Config-Driven

config direction
// Effects shine when they accept semantic config parameters. gsap.registerEffect({ name: "flyIn", effect: (targets, config) => { const fromX = config.direction === "left" ? -config.distance : config.direction === "right" ? config.distance : 0; const fromY = config.direction === "top" ? -config.distance : config.direction === "bottom" ? config.distance : 0; return gsap.fromTo(targets, { x: fromX, y: fromY, opacity: 0 }, { x: 0, y: 0, opacity: 1, duration: config.duration, ease: config.ease } ); }, defaults: { duration: 0.6, distance: 120, direction: "left", ease: "power3.out" } });

Complex Effect — 3D Flip

3D timeline
// Effects can return a timeline and accept complex configs gsap.registerEffect({ name: "cardFlip3D", effect: (targets, config) => { const tl = gsap.timeline(); tl.to(targets, { rotationY: config.angle || 180, duration: config.duration, ease: config.ease }); tl.to(targets, { rotationY: 0, duration: config.duration, ease: config.ease }); return tl; }, defaults: { duration: 0.8, angle: 180, ease: "power2.inOut" }, extendTimeline: true });

Key Takeaways — gsap.effects

gsap.registerEffect({name, effect, defaults}) — Register a named effect
effect(targets, config) — The effect function receives targets and merged config (user config Object.assign'd over defaults)
defaults — Default values for config params. User-supplied values override these.
extendTimeline: true — Makes the effect a chainable timeline method (tl.myEffect())
gsap.effect("name", target, config) — Invoke a registered effect
Semantic configs — Define domain-specific params (direction, distance, angle) for clean API
Return a tween or timeline — Effects can return gsap.to(), gsap.fromTo(), or a gsap.timeline()
DRY principle — Package repeated animation patterns into effects. Change once, update everywhere.
