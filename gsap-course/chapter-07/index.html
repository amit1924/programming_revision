SVG Animations — Morphing, Drawing & Paths

SVG + GSAP is a match made in animation heaven. Learn to draw strokes, morph shapes, and move objects along paths.

1 SVG vs HTML — What's Different?

SVG elements have their own coordinate system (defined by viewBox). GSAP can animate CSS properties (opacity, transform) AND SVG attributes (fill, stroke, d, rx, cx).

CSS properties (work on SVG)

opacity, transform, x, y, rotation, scale

SVG attributes (GSAP-specific)

fill, stroke, strokeWidth, cx, cy, r, rx, ry, d, pathLength

// Animate SVG attributes (not CSS)
gsap.to("circle", {
  attr: {
    cx: 200,
    cy: 100,
    r: 40,
    fill: "#ff6b35"
  },
  duration: 1
});

// Animate CSS properties directly
gsap.to("rect", {
  x: 100,    // CSS transform: translateX
  rotation: 45,  // CSS transform: rotate
  opacity: 0.5,
  duration: 1
});

Critical: SVG attributes must be wrapped in attr: { } inside GSAP. Without it, GSAP treats them as CSS properties (which don't exist on SVG elements). x, y, cx, cy, r, fill, stroke all need attr: { ... }.

2 Common SVG Properties

Shape position

cx, cy, x, y, r, rx, ry

Appearance

fill, stroke, strokeWidth, opacity

Path data

d, pathLength, strokeDasharray

Transform

x, y, rotation, scale (CSS)

// All inside attr: { }
gsap.to("rect", {
  attr: {
    x: 50,
    y: 30,
    width: 120,
    height: 80,
    rx: 20,
    fill: "#ff6b35",
    stroke: "#fff",
    strokeWidth: 3
  },
  duration: 1
});

// CSS transforms work WITHOUT attr wrapper
gsap.to("rect", {
  x: 100,       // CSS translateX
  rotation: 45,  // CSS rotation
  scale: 1.5,     // CSS scale
  duration: 1
});

3 Stroke Drawing — The Signature SVG Effect

The stroke drawing effect makes an SVG path appear to draw itself. It uses stroke-dasharray and stroke-dashoffset — the most iconic SVG animation technique. 

// The formula:
// 1. Get the path length
const path = document.querySelector("path");
const length = path.getTotalLength();

// 2. Set dasharray + offset to HIDE the path
gsap.set(path, {
  strokeDasharray: length,
  strokeDashoffset: length
});

// 3. Animate offset to 0 = path draws in
gsap.to(path, {
  strokeDashoffset: 0,
  duration: 2,
  ease: "power2.inOut"
});

strokeDasharray

Pattern of dashes — set to path length for a single continuous dash

strokeDashoffset

How far the dash is shifted — animate from length to 0

getTotalLength()

Built-in SVG method that returns the exact path length in pixels

4 Path Morphing

Morphing animates a path's d attribute to smoothly transition between shapes. Critical rule: both paths must have the same number and type of commands. 

// Both paths must have same structure
// M... Q... T... T... (same commands)

gsap.to("path", {
  attr: {
    d: "M... Q... T... T..."
    // animate TO this new path data
  },
  duration: 1.5,
  ease: "power2.inOut"
});

// ⚠️ GSAP can't add/remove points
// M3 points → M3 points ✓
// M3 points → M5 points ✗ (jagged)

Morphing constraint: Both paths must have the exact same structure — same number of commands, same command types (M, Q, T, C, etc.). If they don't match, the animation will look jagged or broken.

5 Motion Along a Path

Move an object along an SVG path using GSAP's motionPath plugin or the manual getPointAtLength() approach. We'll use the manual method (no extra plugin). 

// Manual motion along path (no plugin)
const path = document.querySelector("#track");
const length = path.getTotalLength();

// Get position at each progress point
function getPoint(progress) {
  return path.getPointAtLength(progress * length);
}

// Animate by updating position
gsap.to("#dot", {
  motionPath: {
    path: "#track",
    align: "#track",
    alignOrigin: [0.5, 0.5]
  },
  duration: 3,
  ease: "power2.inOut"
});

// Or manual: update x,y in onUpdate
gsap.to({}, {
  progress: 1,
  onUpdate: function() {
    const p = getPoint(this.progress());
    gsap.set("#dot", {
      attr: { cx: p.x, cy: p.y }
    });
  }
});

motionPath plugin (GSAP Club plugin) handles align (auto-rotate to face path direction) and alignOrigin (pivot point). Without it, use the manual getPointAtLength() approach.
