Ch 12 / Draggable + Inertia

Draggable & Inertia

Turn any element into a draggable, throw-able, snap-able interactive widget with Draggable and its built-in inertia physics.

1

Basic Drag — type:"xy"

Draggable.create type
// Draggable.create() accepts a selector and config object. // type: "x" | "y" | "xy" | "rotation" | "scroll" | "scrollTop" | "scrollLeft" Draggable.create(".drag-xy", { type: "xy", bounds: ".drag-area" });
Drag me

Drag the orange box inside the dashed area.
type:"xy" enables both axes.
bounds keeps it inside the container.

2

Inertia — Throw on Release

inertia throwProps
// Inertia is BUILT INTO Draggable in GSAP 3. // Just set inertia: true and it throws on release. Draggable.create(".drag-throw", { type: "x", bounds: { minX: 0, maxX: 400 }, inertia: true }); // Or configure throw resistance: Draggable.create(".drag-throw", { type: "x", inertia: { minVelocity: 10, resistance: 30 } });
Flick

Flick the box — it keeps momentum and slows down naturally

inertia: true adds physics-based throwing.
The box continues moving after you release,
decelerating by friction.

3

Snap — Snap to Grid / Values

snap grid
// Snap to a grid (40px increments) Draggable.create(".drag-snap", { type: "xy", bounds: ".snap-grid", snap: { x: gsap.utils.snap(40), y: gsap.utils.snap(40) } }); // Or snap to discrete values: // snap: { x: [0, 100, 200, 300] }
Snap

The box snaps to a 40x40 grid.
The background dots show the snap points.
snap: { x: snap(40), y: snap(40) }

4

Rotation Drag — Dial / Knob

type:"rotation" snap
// Draggable can rotate elements by dragging Draggable.create(".dial", { type: "rotation", snap: gsap.utils.snap(15) });
0 °

Drag the dial to rotate.
Snaps to 15° increments.
Useful for volume knobs, color wheels, etc.

5

Callbacks — onDrag, onDragStart, onDragEnd

onDrag onDragStart onDragEnd
Draggable.create(".drag-cb", { type: "x", bounds: { minX: 0, maxX: 300 }, onDragStart: function() { log("Drag started at " + this.x); }, onDrag: function() { log("Dragging: " + this.x); }, onDragEnd: function() { log("Drag ended at " + this.x); } });
Log
> Drag to see callbacks...

Each callback receives the Draggable instance as this.
this.x/this.y gives current position.
this.startX/this.startY gives starting position.

6

Bounds & Edge Resistance

bounds edgeResistance
// bounds can be: Element | {minX,maxX,minY,maxY} | "window" // edgeResistance (0-1) creates friction at boundaries Draggable.create(".drag-edge", { type: "x", bounds: { minX: 0, maxX: 350 }, edgeResistance: 0.7 // 0 = no resistance, 1 = stops at edge });
Resist

edgeResistance: 0.7 means 70% friction at the edge.
Drag the box to the boundary — it pushes back.
Adjust the slider and recreate to feel different values.

Key Takeaways — Draggable

type — "x", "y", "xy", "rotation", "scroll"
bounds — Restrict drag area: Element, {minX,maxX,minY,maxY}, or "window"
inertia — true enables throw physics; customize with {minVelocity, resistance}
snap — Snap function or values: gsap.utils.snap(40) or [0,100,200]
edgeResistance — 0-1 friction at boundary edges
callbacks — onDrag, onDragStart, onDragEnd, onPress, onRelease
Draggable.create(selector, config) — Creates one or many draggables from a selector
this.x / this.y — Access current position in callbacks; also this.startX, this.deltaX
