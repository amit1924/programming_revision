3D Transforms with GSAP

GSAP animates rotationX, rotationY, rotationZ, transformOrigin, and perspective — turning flat elements into 3D scenes.

1

rotationX — Tilt Forward/Back

rotationX perspective
// rotationX rotates around the horizontal axis (top-to-bottom) // perspective on the parent creates the 3D depth gsap.to(".box-x", { rotationX: 60, duration: 1, ease: "power2.out" }); gsap.to(".box-x", { rotationX: 0, duration: 1, ease: "bounce.out", delay: 1.2 });
rotationX

Think of a book tilting toward/away from you

2

rotationY — Spin Like a Door

rotationY backface-visibility
// rotationY spins around the vertical axis (left-to-right) // This is the foundation of card-flip effects gsap.to(".box-y", { rotationY: 180, duration: 1.2, ease: "power2.inOut" }); gsap.to(".box-y", { rotationY: 0, duration: 1.2, ease: "power2.inOut", delay: 1.5 });
rotationY

Like a door swinging open

3

rotationZ — Spin 2D (same as rotation)

rotationZ same as rotation
// rotationZ is equivalent to "rotation" — spinning flat in the screen plane gsap.to(".box-z", { rotationZ: 360, duration: 2, ease: "none", repeat: -1 });
rotationZ

Same as rotation — flat spin

4

transformOrigin — Pivot Point

transformOrigin perspective
// transformOrigin changes where the rotation pivots from // "left" → 0% 50%, "right" → 100% 50%, "top left" → 0% 0% gsap.to(".box-origin", { rotationY: 60, transformOrigin: "left", duration: 1 }); gsap.to(".box-origin", { rotationY: 0, transformOrigin: "right", duration: 1, delay: 1.3 });

Key Takeaways — 3D Transforms

rotationX — Tilts around the horizontal axis (like a see-saw)
rotationY — Spins around the vertical axis (like a door)
rotationZ — Same as rotation, spins in the 2D plane
transformOrigin — Sets the pivot point ("50% 50%" default)
perspective — Enables 3D depth on the parent element
transformStyle: "preserve-3d" — Needed so children keep their 3D positions
backface-visibility: hidden — Hides the element when rotated > 90deg (essential for card flips)
translateZ — Moves an element toward/away from the viewer along the Z axis
