from() & fromTo() — Reverse Animations

Chapter 1 taught you gsap.to() — animate to a state. Now learn gsap.from() (animate from a state) and gsap.fromTo() (full control over both ends).

1 The Problem with .to()

gsap.to() animates from the element's current position to a target state. But what if you want an entrance animation — where the element starts off-screen and slides to its natural position?

.to() Element must already be at start position 
gsap.to(".box", {
  x: 300,
  duration: 1
});
// Box jumps to x:0, animates to x:300
// ❌ Can't set where it starts from
.from() Element starts at natural position 
gsap.from(".box", {
  x: -300,
  duration: 1
});
// Box starts at x:-300, animates to x:0
// ✅ Perfect for entrance animations!
.to()
.from()

Key Insight: .to() needs the element to already be at its starting position. .from() needs the element to already be at its final position — then it figures out the start for you. Use .from() for entrances, .to() for state changes.

2 gsap.from() Deep Dive

gsap.from() animates an element from the properties you specify to its current CSS values. Think of it as: "start here, end where you already are."

Syntax 
gsap.from(".selector", {
  x: -200,     // start at -200px
  opacity: 0,    // start invisible
  scale: 0.5,    // start half size
  duration: 1,    // over 1 second
  ease: "power2.out"
});
// Element starts at: x=-200, opacity=0, scale=0.5
// Ends at:           x=0,   opacity=1, scale=1
x
opacity
scale

Transform

x, y, rotation, scale, skewX

Visual

opacity, borderRadius, color

Layout

width, height, top, left, margin

Timing

duration, delay, ease, repeat

Important: The element must already be in its final position in the DOM. .from() only affects the start of the animation. The element's natural CSS is the destination.

3 gsap.fromTo() — Full Control

gsap.fromTo() takes two objects: the from state and the to state. You control both ends explicitly.

fromTo 
gsap.fromTo(
  ".selector",
  {           // ← FROM state
    x: -200,
    opacity: 0,
    scale: 0.5,
    rotation: -20
  },
  {           // ← TO state
    x: 200,
    opacity: 1,
    scale: 1.2,
    rotation: 20,
    duration: 1.5,
    ease: "back.out(1.7)"
  }
);
from
.fromTo
to
.to()

One object. Animates from current to specified state. You control only the destination.

.from()

One object. Animates from specified to current state. You control only the start.

.fromTo()

Two objects. Animates from first to second state. You control everything.

4 Staggered Entrances with .from()

.from() shines for entrance sequences. Combine it with stagger to create beautiful cascading reveals — like a list flying in one by one. 

gsap.from(".entrance-item", {
  x: -80,
  opacity: 0,
  rotation: -10,
  duration: 0.6,
  stagger: 0.15,   // 150ms between each
  ease: "back.out(1.7)"
});
