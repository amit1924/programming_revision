Advanced Techniques

StaggerDirection, callbacks, keyframes, and custom easing — the tools that separate good animations from professional ones.

1 Stagger Direction — staggerFrom

You know stagger. But GSAP can also control which direction the stagger flows — from center outward, from edges inward, reversed order. 

// Default: 0 → 1 (top-left to bottom-right)
gsap.from(".box", {
  stagger: 0.1
});

// Reverse: last element animates first
gsap.from(".box", {
  stagger: {
    each: 0.1,
    from: "end"
  }
});

// From center: middle elements animate first
gsap.from(".box", {
  stagger: {
    each: 0.08,
    from: "center"
  }
});

// Edge: start from edges, meet in center
gsap.from(".box", {
  stagger: {
    each: 0.08,
    from: "edges"
  }
});

// Random: chaotic order
gsap.from(".box", {
  stagger: {
    each: 0.1,
    from: "random"
  }
});

2 Callbacks — onStart, onComplete, onUpdate

Callbacks let you run custom code at specific points during an animation. Click the demo and watch the log — every event fires in order. 

gsap.to(".box", {
  x: 200,
  duration: 2,
  onStart: () => {
    // Fires once — when animation starts
    log("▶ Started!");
  },
  onUpdate: () => {
    // Fires every frame (60x/sec)
    // ⚠️ Keep this lightweight
  },
  onComplete: () => {
    // Fires once — when animation finishes
    log("✅ Complete!");
  },
  onReverseComplete: () => {
    // Fires when reverse finishes
    log("↩ Reversed!");
  }
});

3 Keyframes — Multi-Step Single Tween

A keyframes array lets you define multiple states in a single tween. No timeline needed — perfect for complex, self-contained sequences. 

// Keyframes = array of states
gsap.to(".box", {
  keyframes: [
    { x: 100, duration: 0.5 },
    { y: 80, rotation: 90, duration: 0.4 },
    { x: 0, scale: 0.5, duration: 0.6 },
    { y: 0, rotation: 180, opacity: 0.3, duration: 0.5 },
  ],
  ease: "power2.out"
  // ease applies to ALL keyframes (can override per-frame)
});

// Also works with .from() and .fromTo()!
gsap.fromTo(".box",
  { x: -100, opacity: 0 },
  { keyframes: [
    { x: 50, opacity: 1, duration: 0.4 },
    { x: 100, rotation: 360, duration: 0.6 },
  ]}
);
kf

When to use keyframes: For a single element that goes through multiple states (a box moving right, then down, then back). When to use timeline: For multiple elements that need synchronized timing.

4 Easing Tricks — Custom & Stepped Eases

Chapter 2 covered basic easing. Now go deeper with CustomEase, steps, and expo / sine variants. 

// Stepped ease — jumps between values
gsap.to(".box", {
  x: 200,
  ease: "steps(5)",
  duration: 2
});
// Box jumps in 5 discrete steps

// Expo — dramatic acceleration
gsap.to(".box", {
  x: 200,
  ease: "expo.out"
});
// Starts slow, ends VERY fast — dramatic!

// Sine — smooth, natural motion
gsap.to(".box", {
  x: 200,
  ease: "sine.inOut"
});
// Gentle start and end — like a pendulum

// Rough ease — adds organic randomness
gsap.to(".box", {
  x: 200,
  ease: "rough({strength: 0.3, points: 20})",
  duration: 2
});
// Gives a "hand-drawn" feel

5 Nested Timelines

Timelines can contain other timelines. This lets you build complex, modular animation systems — each component has its own timeline, then they're combined. 

// Child timeline — handles one element
function createBoxAnim(el) {
  const tl = gsap.timeline();
  tl.to(el, { x: 80, duration: 0.4 })
    .to(el, { rotation: 180, duration: 0.3 })
    .to(el, { scale: 0.5, duration: 0.3 });
  return tl;
}

// Parent timeline — orchestrates children
const master = gsap.timeline();

// Nest via .add()
master.add(createBoxAnim(box1))
      .add(createBoxAnim(box2), "-=0.5")
      .add(createBoxAnim(box3), "-=0.3");

// ✅ Modular, reusable, composable

6 gsap.set() & Quick Utilities

Beyond .to(), .from(), and .fromTo(), GSAP offers utility methods for common patterns. 

// gsap.set() —   snapshot, no animation
gsap.set(".box", {
  x: 100,
  opacity: 0.5
});
// Instant. Great for initial states

// gsap.getProperty() — read current value
const x = gsap.getProperty(".box", "x");
// Returns "100" (as string)

// gsap.quickTo() —     pre-bound function
const moveX = gsap.quickTo(".box", "x");
moveX(200); // same as gsap.to(".box", { x: 200 })
// ⚡ Faster — pre-compiled selector + property
// gsap.utils — handy math helpers

// Clamp: keep value in range
const clamp = gsap.utils.clamp(0, 100);
clamp(-50);  // → 0
clamp(150);  // → 100

// Interpolate: map one range to another
const map = gsap.utils.interpolate(
  [0, 500], [0, 100]
);
map(250); // → 50 (midpoint)

// Pipe: compose multiple utils
const safeMap = gsap.utils.pipe(
  map,
  clamp(0, 100)
);
safeMap(1000); // → 100

gsap.quickTo() is a performance gem. It creates a reusable function that's faster than gsap.to() because it pre-compiles the selector and property. Use it in mousemove or scroll handlers for smooth 60fps tracking.
