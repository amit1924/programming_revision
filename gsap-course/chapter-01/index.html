What is GSAP?

Your very first step into the world of web animations. No experience needed. By the end of this chapter, you'll have animated your first element.

1 What is GSAP?

GSAP stands for GreenSock Animation Platform. It's a JavaScript library that lets you create high-performance animations on the web.

Without GSAP: You'd write complex CSS animations, manage JavaScript timers, calculate frame-by-frame movements, and struggle with cross-browser consistency. It's possible — but painful.

With GSAP: You write one line of JavaScript and get smooth 60fps animations that work on every browser. That's it. Seriously — one line.

Real-world analogy: Imagine you have a toy car on your desk. You want it to move from the left side to the right side in 2 seconds. Without GSAP, you'd have to push it step-by-step. With GSAP, you just say: "Move to the right in 2 seconds" — and it happens smoothly.

2 How to Add GSAP to Your Page

You need to include GSAP's library before you can use it. The easiest way is via CDN (Content Delivery Network) — a link that loads the library from the internet. 

<!-- Add this ONE line inside your <head> or before your </body> -->
<script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/gsap.min.js"></script>

That's it. Once this script loads, the global gsap object becomes available. You can now write gsap.to(), gsap.from(), and many more — which you'll learn in this course.

3 Your First Animation: gsap.to()

gsap.to() is the most fundamental method. It animates an element to a new state. Think: "Take this element and animate it TO these new properties." 

// The basic formula:
gsap.to( target, vars );

// Real example — animate a box 300px to the right in 2 seconds:
gsap.to(".box", {
  x: 300,        // move 300px horizontally
  duration: 2   // take 2 seconds
});

The target

What you want to animate. Can be a CSS selector string (".box", "#id"), a DOM element, or even an array of elements.

The vars (variables)

An object containing the CSS properties you want to animate TO, plus special properties like duration, ease, delay, etc.

Key insight:

gsap.to() animates from wherever the element currently is to the values you specify. You don't need to tell it the starting position — GSAP reads the current state automatically.

4 See It In Action

Left side: the code. Right side: the live animation. The code runs automatically when the page loads. 

// Target: the orange box
gsap.to(".demo-box", {
  x: 250,           // move 250px right
  duration: 2,      // over 2 seconds
  rotation: 360,    // full spin
  scale: 1.3,        // grow 30% bigger
  ease: "power2.out" // smooth deceleration
});

5 What Each Property Does

x
x: 250

Moves the element 250 pixels to the right on the X-axis. Negative values move left.

Think: "slide right by 250px"

y
y: 100

Moves the element 100 pixels down on the Y-axis. Negative values move up.

Think: "drop down by 100px"

↻
rotation: 360

Rotates the element 360 degrees (one full spin). You can use any degree value.

Think: "spin around once"

⇱
scale: 1.5

Scales the element. 1.5 = 50% bigger. 0.5 = 50% smaller. 1 = original size.

Think: "grow to 1.5x the original size"

◐
opacity: 0.5

Changes transparency. 1 = fully visible, 0 = invisible, 0.5 = half transparent.

Think: "fade to 50% visible"

⏱
duration: 2

How long the animation takes in seconds. 2 = two seconds. 0.5 = half a second.

Think: "stretch this over 2 seconds"

ease: "power2.out"

This controls the speed curve of the animation. "power2.out" means: starts fast, then slowly decelerates at the end (like a car braking). Without easing, animations feel robotic. With easing, they feel natural. We'll cover easing in depth in Chapter 2.
