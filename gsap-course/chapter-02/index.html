Easing: Making Animations Feel Alive

In Chapter 1, you made things move. In Chapter 2, you'll make them move well. Easing is the secret that separates robotic animations from buttery-smooth, professional ones.

1 What is Easing?

Easing controls the speed curve of an animation — how it speeds up and slows down over time. Without easing, everything moves at a constant speed, which looks robotic. With easing, animations feel natural, weighted, and alive.

🚫 Without easing (linear):
The box moves at the exact same speed from start to finish. Like a conveyor belt — no acceleration, no deceleration. It feels dead.

✅ With easing (power2.out):
The box starts fast, then slowly coasts to a stop. Like a car braking gently. It feels natural and satisfying.

Real-world analogy: Imagine throwing a ball. It leaves your hand fast (ease-out), or imagine a train starting from a station — it starts slow, then speeds up (ease-in). Or a roller coaster going up and over a hill (ease-in-out). Easing mimics how things move in the real world.

2 The Three Directions: .in · .out · .inOut

Every GSAP ease comes in three flavors that control where the speed variation happens:

in

ease-in

Starts slow, ends fast.
Like a train leaving the station.

out

ease-out

Starts fast, ends slow.
Like a car coasting to a stop.

inOut

ease-inOut

Starts slow, speeds up, ends slow.
Like a roller coaster going over a hill.

💡 Rule of thumb: ease-out is the most commonly used for UI animations (elements entering the screen). ease-in is good for elements leaving. ease-inOut is great for continuous motion like a bouncing loader.

// All of these are valid. They get progressively more dramatic:
gsap.to(".box", { x: 300, duration: 1, ease: "power1.out" });  // subtle deceleration
gsap.to(".box", { x: 300, duration: 1, ease: "power2.out" });  // moderate (most common)
gsap.to(".box", { x: 300, duration: 1, ease: "power3.out" });  // strong coast
gsap.to(".box", { x: 300, duration: 1, ease: "power4.out" });  # very dramatic coast

Power1 → Power4: each curve gets more aggressive. The steeper the start, the stronger the deceleration.

5 Special Eases: Back, Elastic, Bounce

These eases add personality. Use them sparingly — they're the punctuation marks of animation.

back.out()

Goes past the target, then snaps back into place. Like pulling a slingshot. 

gsap.to(".box", {
  x: 300,
  ease: "back.out(2)"
  // goes past 300, then
  // snaps back to 300
});

elastic.out()

Oscillates around the target like a rubber band, gradually settling. 

gsap.to(".box", {
  x: 300,
  ease: "elastic.out(1,0.3)"
  // wiggles before settling
});

bounce.out()

Bounces at the end like a ball dropping. Each bounce gets smaller. 

gsap.to(".box", {
  x: 300,
  ease: "bounce.out"
  // bounces at the end
});

Chapter 2 Cheat Sheet

// ─────────── GSAP CHAPTER 2 CHEAT SHEET: EASING ───────────

// Syntax: ease: "name.direction"

// Standard eases (most common)
// .out = starts fast, ends slow (✅ most used)
ease: "power1.out"   // subtle
ease: "power2.out"   // moderate — your default
ease: "power3.out"   // strong
ease: "power4.out"   // very strong

// Directions
ease: "power2.in"     // starts slow, ends fast (leaving)
ease: "power2.inOut"  // slow-slow (continuous motion)
ease: "linear"         // constant speed (robotic — avoid)

// Special eases (use sparingly — they POP)
ease: "back.out(2)"        // overshoots target, then snaps
ease: "elastic.out(1,0.3)" // rubber band wiggle
ease: "bounce.out"         // like a bouncing ball

// ─────────────────────────────────────────────────────────
