Chapter 11: Docker on Windows & Mac

Running Docker on your desktop, whatever OS you use

Windows Options Docker Desktop Win Windows Containers Mac Options Docker Desktop Mac

Docker on Windows — Two Options

Docker gives you two paths on Windows. Choose based on your operating system version and requirements:

Feature Docker Toolbox (Legacy) Docker Desktop for Windows
Virtualization Oracle VirtualBox Hyper-V
Min. Windows Windows 7+ (64-bit) Windows 10 Pro/Enterprise
Performance Slower (VM overhead) Faster (native Hyper-V)
Status Deprecated Recommended

Docker Toolbox includes: VirtualBox, Docker Engine, Docker Machine, Docker Compose, and Kitematic GUI — everything you need in one package.

Note: Docker Toolbox is legacy software. It is no longer actively maintained. Always prefer Docker Desktop for Windows if your system supports it.

Docker Desktop for Windows

Docker Desktop is the modern, recommended way to run Docker on Windows. It provides seamless integration with your OS and excellent performance.

Supported Versions

  • Windows 10 Enterprise
  • Windows 10 Professional
  • Windows Server 2016+
  • Windows 10 Home (no Hyper-V)

Container Types

  • Linux Containers (default)
  • Windows Containers

Docker Desktop uses Hyper-V for virtualization. Hyper-V is Microsoft's native hypervisor — it runs a lightweight VM that hosts the Docker Engine, giving you near-native Linux container performance on Windows.

Seamless Integration

Docker Desktop integrates with Windows natively — you can run Docker commands from PowerShell, CMD, or WSL2 (Windows Subsystem for Linux). It also adds a system tray icon for quick management.

Windows Containers

Docker on Windows supports two isolation modes for Windows containers. Each offers a different balance between resource efficiency and security.

Feature Windows Server Container Hyper-V Isolation
Kernel Shared with host Own kernel per container
Isolation Level Process-level Hypervisor-level (stronger)
Performance Faster Slightly more overhead
Security Standard Higher (trusted multi-tenant)

Available Base Images

Windows Server Core

Full Windows Server experience. Larger image (~4 GB) but supports .NET Framework, IIS, and legacy Windows apps.

Nano Server

Minimal footprint (~1 GB). Optimized for cloud-native apps built with .NET Core, Python, Node.js, etc.

Use Cases: Windows Containers are ideal for lifting and shifting legacy .NET Framework apps, running Windows-specific tools, or hybrid environments where you need both Linux and Windows containers side by side.

Docker on Mac — Two Options

Just like Windows, Docker on macOS has two paths — a legacy option and a modern native option.

Feature Docker Toolbox (Legacy) Docker Desktop for Mac
Virtualization Oracle VirtualBox HyperKit (macOS Hypervisor)
Min. macOS macOS 10.8+ (Mountain Lion) macOS Sierra 10.12+ (2010 Mac+)
Performance Slower (VM overhead) Faster (native Hypervisor)
Status Deprecated Recommended

Docker Toolbox for Mac includes the same components as the Windows version: VirtualBox, Docker Engine, Docker Machine, Docker Compose, and Kitematic GUI.

Note: Toolbox is considered legacy on Mac too. It uses VirtualBox which adds extra overhead. Always use Docker Desktop for Mac if your hardware supports it (Macs from 2010 or later).

Docker Desktop for Mac

Docker Desktop for Mac gives you a native macOS experience. Instead of VirtualBox, it uses Apple's built-in Hypervisor framework and a lightweight VM called HyperKit.

Better Performance

Near-native speed with HyperKit instead of VirtualBox

Linux Containers Only

Unlike Windows, Mac runs only Linux containers

macOS Native UI

Menu bar icon, preferences panel, seamless integration

Verify Docker Desktop for Mac is running 
$ docker version
Client: Docker Engine - Community
 Version:           24.0.6
 OS/Arch:           darwin/amd64     ← macOS 64-bit

Server: Docker Engine - Community
 Engine:
  Version:          24.0.6
  OS/Arch:          linux/amd64      ← Linux VM under the hood

Why Desktop is Better than Toolbox

Docker Desktop uses macOS's native hypervisor instead of VirtualBox. This means faster file sharing, lower resource usage, automatic updates, and a polished UI in your menu bar. It also supports Kubernetes out of the box.

Key Takeaways

Windows users choose between Toolbox (legacy, VirtualBox) and Desktop (modern, Hyper-V)

Mac users choose between Toolbox (legacy, VirtualBox) and Desktop (modern, HyperKit)

Windows Containers offer Server Containers (shared kernel) and Hyper-V Isolation (own kernel)

Docker Desktop is the recommended approach on both platforms

Windows base images: Server Core (full) and Nano Server (minimal)

Docker Desktop for Mac runs Linux containers only via HyperKit
