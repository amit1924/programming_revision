KPIs · KPI Cards & Measures

KPI = Key Performance Indicator: a single headline number that answers one business question at a glance. In this course you build three KPI cards for the salary dashboard — Median Salary, Top Job Platform and Job Count — and later turn them into DAX measures + KPIs in Power Pivot.

A KPI is one number, not a table. It's the answer your boss wants before you open the rest of the dashboard. The rest of the workbook exists to explain it.

Excel has no "KPI card" object (Power BI and Looker give you cards). So Luke uses a backdoor approach — a text box linked to a cell. You'll see exactly that in the next sections.

1

The card is 2 stacked objects

A text box on top (the number) and a rectangle shape behind it (the label + color). Both are Illustrations, not cells.

2

The value lives in a cell

Each number is calculated in a cell (e.g. named median_salary). The text box is just a mirror of that cell — so the card updates automatically.

3

It reacts to the dropdowns

Change the job title from "Data Analyst" to "Data Scientist" and all three cards recompute — that's what makes it a calculator dashboard, not a static picture.

Step 1 — Build the Value in a Cell

The KPI is computed on a helper sheet, named, then shown on the dashboard.

BCD
1Title selectedMedian salaryAnswer
2Data Analyst=XLOOKUP(B2, …)$95,000
1

Rename the cell

Click the cell (I2) → type a friendly name in the Name Box → median_salary. Now any object can reference it by name.

2

Format the cell

Currency, 0 decimal places. The card will inherit this formatting when it links to the cell.

Why name it? You write =median_salary in the text box's formula bar — much clearer than =Sheet1!$I$2.

4

KPI Card #1 — Median Salary

XLOOKUP pulls the median salary for whichever job title is selected.

AB
1Job titleMedian salary
2Data Analyst$95,000
3Data Scientist$120,000
4Data Engineer$105,000
=XLOOKUP(B2, A2:A4, B2:B4, "no results")

Watch for missing titles. If the selected title isn't in the list, XLOOKUP returns #N/A — pass a "no results" message as the 4th argument so the card never shows an error.

→

Result

Named cell median_salary → later linked to a text box as =median_salary.

5

KPI Card #2 — Top Job Platform

Count jobs per source (job_via), sort descending, take the winner, clean the "via " prefix.

AB
1Job viaCount
2via Snagajob265
3via LinkedIn210
4via ZipRecruiter180
5via Indeed140
1

Count each source

A COUNTIF-style formula down the unique job_via values — how many jobs came from each platform.

2

Sort high → low

Select all, sort by the count column, descending — the biggest number goes to the top. Row 2 is now the winner: Snagajob.

3

Clean the "via " prefix

Values say "via Snagajob" — strip it so the card reads nicely:

=SUBSTITUTE(A2, "via ", "") → Snagajob

Bias-free: "Top" here means most jobs posted, not highest salary. Pick the metric that answers the question you actually asked.

6

KPI Card #3 — Job Count

COUNTIFS counts jobs matching all the dropdown filters — country, title and job type.

ConditionDropdown cellSelected
Country$F$2United States
Job title$A$2Data Analyst
Job type$C$2Full-time
=COUNTIFS(Country, $F$2, Title, $A$2, Type, $C$2) → 537
1

Three conditions, three dropdowns

Every dropdown selection is absolute-referenced ($) so the formula looks at exactly the chosen country, title and type.

2

Pull it into a named cell

Wrap in XLOOKUP to the matching row, or reference directly → name it count → link the card to =count.

No results? A count can hit zero and look broken. Fall back to "no results" so the card stays friendly instead of showing 0 or #N/A.

7

The Backdoor Trick — Text Box = Cell

Excel has no KPI card object, so a text box becomes the card and a formula bar link makes it live.

1

Insert a text box

Insert → Illustrations → Text Box → drag it onto the dashboard where the card should go.

2

Link it — DON'T type the value

Click the box so there's no blinking cursor inside → click the formula bar → type =median_salary → Enter. The box now mirrors the cell and picks up its formatting automatically.

3

Reformat the box

Currency, 0 decimals, bold, centered, bigger font — the box, not the cell, gets the display formatting.

"It's a rectangle, not a cell." The value is technically floating over the sheet, but it is still calculated inside the workbook — so it stays live and correct.

8

Making It Look Like a Card

Add a colored shape behind the number for the label + polish the dashboard.

1

Shape behind the number

Insert → Illustrations → Shapes → Rectangle. Fill it blue, white text — type the label MEDIAN SALARY, bold, 20pt, centered.

2

Send to back

Right-click shape → Shape Format → Send Backwards → Send to Back, so the number text box sits on top of the label rectangle.

3

Clean outlines

Text box → remove its outline (No Outline) and stretch it edge-to-edge. Do the same for every card so they blend in.

4

Reuse with Format Painter

Copy the finished card with Format Painter to instantly style the other two, then rename their labels (Top Job Platform, Job Count) and re-link each to its own cell.

5

Dashboard polish

Remove gridlines (View → uncheck Gridlines), switch shape outlines to none, widen columns, add a merged title ("Data Science Salary Calculator") with a Heading style, and hide headings for the final look.

A Composite KPI — Job Rank

Normalize each metric 0→1, weight them to your bias, and rank jobs in one score.

Job titleCountCount normSalary normWFH normRank (weighted)
Data Analyst5371.000.720.330.72
Data Scientist900.171.001.000.53
Data Engineer1530.290.840.560.47
Cloud Engineer00.000.900.000.27
Rank = 0.45 × count_norm + 0.30 × salary_norm + 0.15 × wfh_norm
1

Normalize each metric to 0–1

Highest value → 1, lowest → 0. This puts "count", "salary" and "WFH %" on the same scale so they can be compared and combined.

2

Apply YOUR weights

Weights are "all my bias" — Luke picks roughly 0.45 / 0.30 / 0.15. This is exactly how KPIs are often built: a weighted blend of metrics.

One metric per color. Too many conditional-formatting colors at once overwhelms the reader. For a KPI view pick one clear visual: data bars for counts, a color scale for salaries, a highlight rule for "> $100,000".

Power Pivot KPIs — Measures in DAX

In the data model, KPI values become explicit DAX measures you can reuse everywhere.

Median Salary := MEDIAN(data_jobs_salary[salary_year_avg])
1

Power Pivot tab → Create Measure

The Power Pivot ribbon has buttons to create measures and KPIs. Pivot value settings have no "Median" option — DAX adds it: := MEDIAN(…).

2

Explicit vs implicit measures

Explicit = a measure you defined with DAX (shown with an fx icon — reusable, composable). Implicit = the auto-aggregation you get by dragging a field into Values — fast but throwaway.

PartWhat it isExample
Measurethe valueMedian Salary
Targetthe goal$110,000
Statushow closegreen / amber / red

A real KPI = measure + target + status. The card on the sheet shows the measure; the Power Pivot KPI adds a target and color status so anyone can see at a glance whether the goal is hit.
