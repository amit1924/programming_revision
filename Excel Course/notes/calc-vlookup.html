VLOOKUP

VLOOKUP = Vertical Lookup. You hand it an ID, it searches the first column of your table, then returns the matching value from any column to the right. See it on real employee data below.

Excel reads it like this: 🔍 "Search for 103 inside the table from A2 to D6. When you find it, return the value from the 2nd column."

Understanding FALSE vs TRUE

The 4th argument decides: exact match, or nearest lower match.

1

FALSE — Exact match (Recommended)

Finds the ID that is exactly equal. Works even when the table is unsorted. Use this almost always.

=VLOOKUP(103, A2:D6, 2, FALSE) → Priya
TRUE?FALSE?
Nearest lower matchExact match only
Rarely usedMost commonly used
Requires sorted 1st columnWorks even if unsorted
2

TRUE — Approximate match (grade example)

Searching 82 picks the largest value that is ≤ 82 → 75 → grade B.

=VLOOKUP(82, A2:B5, 2, TRUE)
AB
1MarksGrade
20Fail
350C
475B
590A

82 → B, because 82 falls between 75 and 89. With TRUE the first column must be sorted ascending, or you'll get wrong results.

9

Common Errors

Three classic mistakes — and how to fix them.

DANGER ZONE
1

#N/A — ID not found

Employee 999 doesn't exist in the table.

=VLOOKUP(999, A2:D6, 2, FALSE)
Result
#N/A

Fix it with IFERROR:

=IFERROR(VLOOKUP(F2, A2:D6, 2, FALSE), "Not Found")

Now instead of #N/A, you get the friendly message "Not Found".

2

Wrong column number

There is no 7th column inside A2:D6.

=VLOOKUP(101, A2:D6, 7, FALSE) → #REF!
3

VLOOKUP only looks RIGHT

VLOOKUP always searches the first column of the table. If Employee ID is not column 1, it fails.

AB
1NameEmployee ID
2Amit101
3Rahul102
=VLOOKUP(101, A2:B3, 1, FALSE) → #N/A

Why? The first column is Name, so it searches names (Amit, Rahul), not IDs. To fix: put Employee ID in the first column, or use XLOOKUP which can search any column.
