Excel — XLOOKUP (Lookup Functions)
Step by step
The modern replacement for VLOOKUP & HLOOKUP

XLOOKUP

XLOOKUP is any-direction lookup: search any column, return from any column, on the left or the right — and it shows a friendly message when nothing is found, with no IFERROR needed.

lookup value (what you search) returned result formula / match
1

The Problem — VLOOKUP's Annoying Rules

VLOOKUP works, but it comes with three big frustrations.

MOTIVATION
#VLOOKUP ruleWhy it hurts
1Search column must be the FIRST columnCan't look up Employee ID when it sits on the right
2Returns only columns to the RIGHTCan't bring back a value from the left
3Numbering: col_index_numInsert a column and every formula breaks

Bonus: a missing value gives ugly #N/A unless you nest IFERROR around it.

2

XLOOKUP Fixes All Three

Separate arrays for searching and returning = full freedom.

=XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found], [match_mode], [search_mode])
PartMeaning
lookup_valueWhat to search for
lookup_arrayThe column/row to search (ANY column)
return_arrayThe column/row to return from (ANY column)
if_not_foundMessage when nothing matches (optional)
match_mode0 exact, -1 nearest smaller, 1 nearest larger, 2 wildcard
search_mode1 first-to-last, -1 last-to-first, 2/‑2 binary

Note: only the first three arguments are required. The last three are optional and have defaults that work for most cases.

The Big Win — Search ANY Column

VLOOKUP fails here. XLOOKUP doesn't even blink.

KEY SUPER-POWER
1

Name is now in the FIRST column

Find the employee by name, return their Employee ID.

AB
1NameEmployee ID
2Amit101
3Rahul102
4Priya103
=XLOOKUP("Rahul", A2:A4, B2:B4) → 102

Same job in VLOOKUP: =VLOOKUP(101, A2:B3, 1, FALSE) → #N/A. It could never search the Name column because it wasn't the first one. XLOOKUP just needs a lookup array and a return array — the order doesn't matter.

Built-in "Not Found" — No IFERROR Needed

The 4th argument handles missing values on its own.

CLEANER
FG
1Employee IDName
2999"Not Found"
=XLOOKUP(F2, A2:A6, B2:B6, "Not Found") → "Not Found"

vs VLOOKUP: =IFERROR(VLOOKUP(F2, A2:D6, 2, FALSE), "Not Found") — same result, but XLOOKUP does it in one clean function.

match_mode — Exact or Approximate

The 5th argument replaces VLOOKUP's confusing TRUE/FALSE.

match_modeMeaningLike VLOOKUP's
0Exact match (default)FALSE
-1Exact, else nearest SMALLER valueTRUE
1Exact, else nearest LARGER value—
2Wildcard match (* and ?)—
1

Grade example — approximate match

Marks of 82 pick the nearest smaller grade boundary (75 → B). Lookup array must be sorted ascending.

AB
1MarksGrade
20Fail
350C
475B
590A
=XLOOKUP(82, A2:A5, B2:B5, "No grade", -1) → B

82 → B, because 82 falls between 75 and 89. With -1 the lookup array must be sorted ascending.

8

search_mode — Direction of Search

New superpower: find the LAST match instead of the first.

search_modeMeaning
1Search first-to-last (default)
-1Search last-to-first (find the LAST match)
2Binary search — requires sorted array
-2Binary search — requires sorted array (reverse)
1

Find the last sale of a product

"Mouse" appears twice. Default search returns the first; -1 returns the last.

AB
1ProductAmount
2Mouse500
3Keyboard1500
4Mouse900
5Monitor12000
=XLOOKUP("Mouse", A2:A5, B2:B5, "Not Found", 0, -1) → 900

With search_mode -1 you get the 900 (last "Mouse" row). VLOOKUP can only ever give you the first match.

XLOOKUP vs VLOOKUP — Side by Side

Same question, both answers.

FeatureXLOOKUPVLOOKUP
Search any column✅ Yes❌ First column only
Return from the left✅ Yes❌ Right only
Survives inserting a column✅ Yes❌ Breaks
Missing value message✅ Built-in argument❌ Needs IFERROR
Find the LAST match✅ search_mode -1❌ Never
Lookup columns/rows✅ Both (it's universal)Columns only (HLOOKUP does rows)

Bottom line: XLOOKUP replaces BOTH VLOOKUP and HLOOKUP. It searches columns or rows, any direction, with a built-in fallback. Learn it once, use it everywhere.

Quick Cheat Sheet

Copy-paste ready patterns.

MEMORIZE
FormulaPurpose
=XLOOKUP(A2, B2:B20, C2:C20)Exact lookup, return another column
=XLOOKUP(A2, B2:B20, C2:C20, "Not Found")Lookup with a friendly "Not Found"
=XLOOKUP(A2, C2:C20, B2:B20)Lookup in column C, return from column B (left)
=XLOOKUP(A2, B2:B20, C2:C20, "?", -1)Approximate match (grades, ranges)
=XLOOKUP(A2, B2:B20, C2:C20, "?", 0, -1)Return the LAST match, not the first

Remember: =XLOOKUP(lookup_value, lookup_array, return_array) — search array and return array can be in ANY order. Lock ranges with F4 before copying.
