Cell Referencing

Relative · Absolute ($) · Mixed · F4
Relative ReferenceDEFAULT

Changes when you drag the formula. =A1 becomes =A2, =A3...

ABC
110=A1*220
220=A2*240
330=A3*260

Each row auto-updates to match its row!

Absolute Reference ($)F4 KEY

Stays the same no matter where you drag. =$A$1 always points to A1.

ABC
10.08Tax RateAmount
2Price=$A$1*1008
3Price=$A$1*20016

$A$1 stays locked. Change tax rate once, all cells update!

Mixed Reference$A1 or A$1

Lock only the column OR only the row.

ABC
15=A1*$B$115
210=A2*$B$130

Press F4 (Mac: Fn+F4) to cycle: A1 → $A$1 → A$1 → $A1

Common Errors

#DIV/0! · #N/A · #VALUE! · #REF! · #NAME?
#DIV/0!

Dividing by zero. Fix: check your divisor isn't blank or zero.

AB
1=10/0#DIV/0!
#N/A

Value not found. VLOOKUP/XLOOKUP can't find the lookup value.

AB
1=VLOOKUP("XYZ",A:B,2,FALSE)#N/A
#VALUE!

Wrong data type. Adding text to a number, or wrong range sizes.

AB
1="hello"+5#VALUE!
#REF!

Cell reference is invalid. Usually happens after deleting a column/row used in a formula.

#NAME?

Excel doesn't recognize the function name. Typo like =SUMM(A1) instead of =SUM(A1).

💡 Fixing Errors
  • • IFERROR: =IFERROR(formula, "fallback")
  • • Use Evaluate Formula (Formulas tab) to step through
  • • Trace Precedents shows which cells feed in
  • • Ask ChatGPT/Claude: paste the formula + error
