Excel — HLOOKUP (Lookup Functions)
Step by step
Search the 1st ROW, grab a value from a row below it

HLOOKUP

HLOOKUP = Horizontal Lookup. You hand it an ID, it searches the first row of your table, then returns the matching value from any row below. The twin of VLOOKUP, but for data laid out sideways.

Syntax — What Each Part Means

Identical to VLOOKUP, except the number picks a ROW.

=HLOOKUP(lookup_value, table_array, row_index_num, [range_lookup])
Example valuePartMeaning
103lookup_valueWhat to search for
A1:F4table_arrayTable containing the data
2row_index_numReturn value from the 2nd row (Name)
FALSErange_lookupFind an exact match
=HLOOKUP(103, A1:F4, 2, FALSE) → Priya

VLOOKUP vs HLOOKUP: VLOOKUP searches a column and returns a column → col_index_num. HLOOKUP searches a row and returns a row → row_index_num. Same logic, different direction.

Understanding FALSE vs TRUE

The 4th argument decides: exact match, or nearest lower match.

1

FALSE — Exact match (Recommended)

Finds the ID that is exactly equal. Works even when the table is unsorted. Use this almost always.

=HLOOKUP(103, A1:F4, 2, FALSE) → Priya
TRUE?FALSE?
Nearest lower matchExact match only
Rarely usedMost commonly used
Requires sorted 1st rowWorks even if unsorted
2

TRUE — Approximate match (grade example)

Searching 82 picks the largest value that is ≤ 82 → 75 → grade B.

=HLOOKUP(82, A1:C5, 2, TRUE)
ABC
105075
2FailCB
390A

82 → B, because 82 falls between 75 and 89. With TRUE the first row must be sorted ascending, or you'll get wrong results.

9

Common Errors

The same classic mistakes as VLOOKUP — now in horizontal form.

DANGER ZONE
1

#N/A — ID not found

Employee 999 doesn't exist in the table.

=HLOOKUP(999, A1:F4, 2, FALSE)
Result
#N/A

Fix it with IFERROR:

=IFERROR(HLOOKUP(A7, A1:F4, 2, FALSE), "Not Found")

Now instead of #N/A, you get the friendly message "Not Found".

2

Wrong row number

There is no 9th row inside A1:F4.

=HLOOKUP(101, A1:F4, 9, FALSE) → #REF!
3

HLOOKUP only looks DOWN

HLOOKUP always searches the first row of the table. If Employee ID is not row 1, it fails.

ABCD
1NameAmitRahulPriya
2Employee ID101102103
=HLOOKUP(101, A1:D2, 1, FALSE) → #N/A

Why? The first row is Name, so it searches names (Amit, Rahul…), not IDs. To fix: put Employee ID in the first row, or use XLOOKUP which can search any row.
