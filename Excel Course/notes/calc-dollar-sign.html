Excel — The $ Dollar Sign (Absolute & Mixed References)
Step by step
The $ is a "handcuff" — it stops a reference from moving when you copy a formula

The $ Dollar Sign

Relative references move when you drag. Absolute references ($A$1) stay put. Mixed references lock only one part. The F4 key cycles through them all.

relative (moves) absolute (locked) mixed (half locked)
1

The Four Reference Types in One Table

Where the $ sits decides what stays fixed when the formula is copied.

THE CONCEPT
TypeNotationCopied downCopied right
RelativeA1row moves → A2, A3…column moves → B1, C1…
Absolute$A$1stays A1stays A1
Mixed (col locked)$A1row moves → $A2, $A3…stays $A1
Mixed (row locked)A$1stays A$1col moves → B$1, C$1…

Memory hook: the $ locks whatever it sits in front of. $A$1 = locked cell. $A1 = locked column, free row. A$1 = locked row, free column.

2

The F4 Shortcut — Cycle the $

Click the reference in the formula bar, press F4, watch it cycle.

A1  →  $A$1  →  A$1  →  $A1  →  A1 … and back around
1

Put the cursor on the reference

Click the cell with the formula, then click the reference inside the formula bar (or press F2 and move the cursor onto it).

2

Press F4

Each press cycles: relative → absolute → row-locked → column-locked → back to relative. Stop at the one you need, press Enter.

No mouse needed: type the formula without $, press F4 while the reference is highlighted, and the $ appears instantly. This is the fastest way to lock a reference.

Relative (A1) — The Default

No $ at all. The reference shifts along with the formula when you copy or fill.

Relative is great for "same pattern, next row". It only breaks when the value you need does NOT move with the formula — that's when you bring in the $.

Absolute ($A$1) — Stay Put

The classic: multiply every row by ONE fixed number (tax, commission, exchange rate).

ABCD

3Data Scientist120000=B3*$C$112000
4Data Engineer105000=B4*$C$110500
=B2 * $C$1 (C1 holds 0.10 — locked so it never drifts)

C4drag down →=B4*$C$1$C$1 still C1 ✓

One cell drives everything: B moves (relative), $C$1 stays (absolute). Change the tax rate once in C1 and the whole column recalculates.

Dragging down must keep reading the top header (row 1) → $1 locks the row.

Golden pattern: if a formula lives in a grid, its corner cells are always mixed — one reference follows the column header, the other follows the row header.

Real Course Example — Locked Dropdowns in the Dashboard

The salary dashboard's COUNTIFS locks the 3 dropdown cells so every row checks the SAME selection.

ABCDEF
1TitleSalaryTypeCountCountrySelected
2Data Analyst95000Full-time=COUNTIFS(…)United States$F$2
3Data Scientist120000Full-time=COUNTIFS(…)……
=COUNTIFS(Country,$F$2, Title,$A$2, Type,$C$2)
1

The dropdown cells are locked ($F$2, $A$2, $C$2)

Fill the formula down a whole list — every row still compares against the ONE cell the user picked in the dropdown.

2

Without the $, it silently breaks

A plain F2 would drift to F3, F4… comparing against empty cells → the count turns 0. The $ is what makes the dashboard respond to one dropdown.

Running Total — Lock the Start, Move the End

A growing SUM where only the first cell of the range is locked.

ABC
1MonthSalesRunning total
2Jan1000=SUM($B$2:B2)
3Feb1500=SUM($B$2:B3)
4Mar2000=SUM($B$2:B4)
CellStoredSumsResult
C2=SUM($B$2:B2)B21000
C3=SUM($B$2:B3)B2:B32500
C4=SUM($B$2:B4)B2:B44500

The trick: lock the START of the range $B$2, let the END drift (B2 → B3 → B4). The range grows as you fill down.

Common Mistakes

How the $ quietly corrupts your numbers.

MistakeWhat happensFix
Forgot the $ on a fixed numberfill down → references drift → wrong results (e.g. tax 9500, 10800, 10815…)use $C$1
Locked everything ($A$1 everywhere)formula never adapts → every row computes the SAME valuelock only what must stay
Locked the wrong half ($A1 vs A$1)grid formulas fill in the wrong directioncorner cells = mixed
Locked dropdowns? No.COUNTIFS range itself drifts when copiedlock lookup ranges too

Worst case: the formula LOOKS right and returns a number — but it's the wrong number. Always spot-check the first and last filled cells before trusting a drag-fill.
