Add-ins & Forecast Sheet

Enable • Forecast • Confidence
Enabling Add-ins

Three types: Web, Excel (COM), COM. The key ones for data analysis:

Analysis ToolPak — Statistical tests, histograms, moving averages, regression, sampling
Solver — Optimization with constraints, multiple variable inputs
How to enable:
1. File → Options
2. Add-ins → Manage: Excel Add-ins → Go
3. Check Analysis ToolPak and Solver → OK

Analysis ToolPak

Stats • Histograms • Moving Avg • Correlation
Available Tools
📊 Histogram — Frequency distribution with bins
📈 Moving Average — Smooth out fluctuations
🔢 Rank & Percentile — Position within data
📋 Descriptive Statistics — Mean, median, mode, std dev, etc.
🔗 Correlation — Relationship between variables
📉 Regression — Linear modeling and prediction
🎲 Sampling — Random or periodic sampling
🧪 t-Tests / F-Tests — Statistical hypothesis testing

Pro Tips
Add-ins once — Enable Analysis ToolPak and Solver once; they stay active for all workbooks.
Forecast confidence — Adjust the confidence interval in the Forecast Sheet options. 95% is default.
Solver constraints — You can add integer constraints (e.g., number of employees must be whole).
Data Table speed — Large data tables can slow down Excel. Use F9 to manually recalculate.
Scenario Summary — Scenario Manager creates a summary sheet with all scenarios and result cells.
Moving Average interval — An interval of 7 smooths weekly fluctuations; 30 smooths monthly.
