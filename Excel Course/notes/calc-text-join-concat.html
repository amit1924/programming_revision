Join, Auto-Fill & Consolidate

Out of separate columns — make one. Out of repeated sheets — make one. This page walks you through joining text (&, CONCAT, TEXTJOIN), dragging fills, and combining whole data ranges (Consolidate, Append) on real rows and cells.

Numbers & dates follow the same trick

Formulas drag too: the fill handle is the same one used to copy any formula down a column — it moves relative references with it.

3

Step-by-Step: TEXTJOIN a whole range

Combine many cells with a separator in ONE formula

1

Know the recipe

=TEXTJOIN(sep, ignore_empty, range)

  • sep — the glue between items, in quotes: ", "
  • ignore_empty — TRUE skips blank cells, FALSE keeps their gaps
  • range — one or more blocks to join
2

Type it next to the block

In D7 write =TEXTJOIN(", ",TRUE,A7:A10).

A
7Sales
8IT
9Ops
10Finance
3

It collapses into one sentence

Result: Sales, IT, Ops, Finance. Great for a dropdown list, an email recipient string or a summary.

vs CONCAT: CONCAT joins cells exactly as given; TEXTJOIN inserts your separator and can ignore blanks. Use TEXTJOIN when you want a clean, delimited list.

4

"Merge" means two different things — don't confuse them

Merge TEXT (this page)

Glue the contents of cells into ONE cell.

A1"David" + B1"Liu" → David Liu
=A1&" "&B1

Merge & Center (elsewhere)

Joins the cells themselves into one wide cell for a title.

ABC
1Sales Report

Only the top-left value survives cell merge.

Same word "merge", two jobs. Text merge = keep the words; cell merge = make a big box. Both exist; they don't replace each other.

1

Open Consolidate

Menu Data > Consolidate. This queues up ranges and a function to merge them.

2

Pick the function (default = Sum)

Leave Sum. You can also count, average or find max/min across the sheets.

3

Add each source range

Click into Sheet N → select A1:C3 → Add. Then the same for Sheet2's A1:C3. Up to 255 ranges allowed.

4

Turn on labels

Tick First column (Product) and First row (Jan/Feb) so the totals line up by name — not just by position.

5

Check the combined result

Apples Jan = 100 + 60 = 160. Pears Feb = 90 + 50 = 140. Your regions are now one table.

ABC
1ProductJanFeb
2Apples160190
3Pears120140

Ranges with the same label are added / summed; labels appearing in only one range still appear.

Consolidate = additive/aggregating. It sums values by matching labels. If you instead want to stack rows, use Append (next).

6

Append / stack rows into one list

Same columns, more sheets → put the rows one under the other

1

Select the source rows

On Sheet2, select the data rows (e.g. A2:C4) — skip the header, or add it only once to the combined sheet.

2

Copy them

Menu Edit > Copy (or Ctrl+C).

3

Paste right below the existing data

Jump to the last filled row + 1, then Edit > Paste. The two blocks now form one continuous table; apply filters & formatting to the whole range.

ABC
1CustomerRegionAmount
2MoriNorth400
3NiuNorth260
4OkaSouth390
5PineWest180
6QuillEast215

Rows 5–6 were appended = pasted in from Sheet2.

4

Or make it automatic formulas

Instead of pasting, reference the cells: in the combined sheet put =Sheet2.A2 in each row — a "live append" that updates when Sheet2 changes.

Which to use? Need added totals? → Consolidate. Need one long list? → Append (stack rows, keep details).
