3

Fix the case (UPPER / LOWER / PROPER)

Then combine every fix into one tidy cell

UPPER

everything → capitals

=UPPER(A2)
HELLO → HELLO
LOWER

everything → small

=LOWER(A2)
HELLO → hello
PROPER

each word → capital

=PROPER(A2)
john smith → John Smith
5

Combine the fixes in one formula

Need spaces AND capitalization gone? Nest them: =PROPER(TRIM(A2)). Calc runs TRIM first (innermost), then PROPER.

ABC
1Raw=TRIM(A2)=PROPER(TRIM(A2))
2 john SMITH john SMITHJohn Smith

Remove duplicate rows (menu)

A customer list with repeats — remove the extras in a few clicks

1

Select the list

Select the whole column (click its letter A) including the header.

2

Open the dialog

Menu Data > More Filters > Standard > (Uncheck duplicates)… or the quick Data → Remove Duplicates.

3

Confirm which columns to compare

Calc keeps the FIRST occurrence and removes later repeats. A confirmation tells you how many rows were removed.

4

Watch 6 rows become 4

Because headings differ in case/spaces, clean first (Part 2/3) so "acme group" matches "ACME Group".

Real flow: TRIM first → PROPER → then remove duplicates. Same "person" always looks identical, so dedupe works.

30-Second Cheat Sheet

Remove spaces

=TRIM(A1) fixes gaps.

Fix caps

=PROPER(A1) · =UPPER(A1) · =LOWER(A1)

Slice text

=LEFT(A1,4) · =RIGHT(A1,4) · =MID(A1,2,3)

Swap parts

=SUBSTITUTE(A1," ","_")

Count

=LEN(A1) how many chars.

Dedupe

Data → Remove Duplicates
