Sorting · Grouping · Filtering

Three ways to control a big list of data. Sort reorders rows, filter hides rows you don't need, group folds related rows into a single bundle. All three live on the Data tab.

Sorting — One Column at a Time

Reorder the whole table by a single column: A→Z or Z→A, smallest→largest or largest→smallest.

1

Pick the column to sort by

Salary — we want cheapest first.

2

Data tab → Sort & Filter → Sort Smallest to Largest

The whole table reorders together — rows stay intact, they just change places.

Golden rule: never sort just one column alone. If you select only column E and sort, the salaries move but their rows don't → your data is destroyed. Always sort the whole table.

Multi-Level Sort — Two Keys at Once

First group by country, THEN by salary inside each country. Open Custom Sort to add levels.

1

Open Custom Sort and add two levels

Data tab → Sort & Filter → Custom Sort → Add Level.

LevelColumnSort OnOrder
1CountryValuesA to Z
2SalaryValuesLargest to Smallest

Read it as: sort by Country first; whenever countries are equal, sort by Salary (big first).

Filtering — Turn On the AutoFilter

Filters HIDE rows you don't want. Nothing is deleted — it's all still there.

HOME TAB TOO
1

Select the header row, then apply the filter

Editing → Sort & Filter → Filter (also on the Data tab). Every header gets a tiny dropdown arrow.

ABCDEF
1Job Title ▼Company ▼Location ▼Type ▼Salary ▼Country ▼

Those ▼ dropdowns are your filter controls.

2

Filter by a value — only Data Analyst jobs

Open Job Title ▼, uncheck Select All, tick only Data Analyst.

ABCDEF
1Job TitleCompanyLocationTypeSalaryCountry
2Data AnalystTikTokMountain View, CAFull-time85000United States
3Data AnalystFlipkartBengaluruFull-time40000India
— rows 4–7 hidden (Data Engineer, Data Scientist, Marketing Lead) —

Only matching rows stay visible. Row numbers jump (4→7 gone) — that's how you know a filter is on.

3

Stack filters — narrow it down further

Also open Type ▼ → Full-time, then Country ▼ → United States.

ABCDEF
1Job TitleCompanyLocationTypeSalaryCountry
2Data AnalystTikTokMountain View, CAFull-time85000United States

Filters AND together: a row shows only if it passes every filter.

4

Clear when you're done

Editing → Sort & Filter → Clear, or Clear Filter from a header's dropdown. All rows come back.

Clearing a filter never deletes data — it just unhides everything.

The numbered buttons (1, 2, 3) at the top-left collapse everything to a level. Group more rows to unlock them.

Ungroup to undo

Select the grouped rows → Data tab → Ungroup. You can also group COLUMNS the same way.

8

Which Tool When?

They feel similar, but each solves a different problem.

GoalUseWhat it does
Reorder rows by a columnSortChanges the order of the rows
Show only rows matching criteriaFilterHides rows temporarily
Bundle rows, collapse detailsGroupAdds outline bars + collapse buttons
Auto totals per categorySubtotalGroups + inserts SUM under each

Combo tip: filter first to shrink the data, then sort the visible rows, then group for a tidy summary — the tools work together.
