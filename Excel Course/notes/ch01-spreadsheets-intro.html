Worksheets

Your canvas — cells, rows, columns, and how to put stuff in them

What's a Worksheet?

A worksheet (or just "sheet") is a single page inside Excel. It's the tab you see at the bottom labeled Sheet1. Think of it as one page in a notebook. You can have many sheets in one Excel file.

Cells = Rows + Columns

Every cell has an address. The column letter comes first, then the row number. B2 = column B, row 2. There are ~1M rows and columns go up to XFD.

3 Python 5 Advanced TRUE

B2 has difficulty 4. Column B = difficulty, Row 2 = Excel row.

Data Types You Can Enter

Numbers

Just type digits: 4, 50000. Excel aligns them right.

Text

Words like "Excel", "Beginner". Left-aligned automatically.

Boolean (True/False)

Type TRUE or FALSE. Excel auto-capitalizes it!

Dates

Type 8/27/2024. Excel stores dates as numbers internally (1 = Jan 1, 1900).

Autofill — Drag to Fill

Select a cell, grab the little square at the bottom-right corner (the fill handle), and drag. Excel automatically fills the rest. But it's smart — it detects patterns!

ABCD
1 Action Value 1 Value 2 Result
2 Type 1, drag down 1 → 1
3 (autofilled) 2 → 1
4 Type 1 & 2, drag down 1 2 3
5 (autofilled) 3 4 5
6 Date, drag down 8/27/2024 → 8/28/2024
7 (autofilled) 8/29/2024 → 8/30/2024
Autofill detects patterns: 1,2 → 3,4,5... Dates increment by 1 day. To copy exact same value, hold Ctrl while dragging.

Copy & Paste (Keyboard Shortcuts)

The instructor emphasizes: use shortcuts, not the mouse. It saves tons of time.

Pro tip: After copying (Ctrl+C), you'll see "marching ants" (dashed border) around the cell. Press Esc to cancel if you change your mind.

Your First Formula

Every formula starts with =. Instead of typing a number, you can reference another cell.

ABCDEF
1 Skill Difficulty (1-5) Experience Annual Salary Bonus Max Difficulty * 2
2 Excel 4 5 80000 8000 =B2*2
3 Python 5 2 120000 12000 10
4 SQL 3 4 90000 9000 6

What's happening? In cell F2, the formula =B2*2 says: "Take whatever is in B2 (which is 4) and multiply it by 2." Result = 8. When you drag F2 down, Excel automatically changes it to =B3*2, =B4*2 etc. That's called relative referencing.

Ranges — A Group of Cells

A range is a rectangle of cells. Written as A1:G6 = top-left to bottom-right. You can select entire columns (A:A) or entire rows (5:5).

Workbooks

The file itself — moving data between sheets and files

Workbook vs. Worksheet

Workbook

The entire Excel file (e.g., data_jobs.xlsx). It's like a notebook containing many pages.

Worksheet

A single tab inside the workbook (Sheet1, Jan, Data). One workbook can have many sheets.

3 Ways to Move Data Between Sheets

1 Formula Reference

Type = in the target cell, click the source sheet, select the cell/range, press Enter.

AB
1 Sheet Reference Value
2 =Jan!A1:P3103 Copies entire Jan sheet data

Jan!A1 means "in the sheet named 'Jan', cell A1". The ! separates sheet name from cell.

2 Copy & Paste

Select source range Ctrl+C, go to target sheet, Ctrl+V. Quick but can miss data.

3 Move or Copy Sheet

Right-click the sheet tab → Move or Copy → select target workbook → check Create a copy → OK. This is the recommended method — no risk of missing data.

Best Practice: Always use "Move or Copy" when moving entire sheets between workbooks. Formula references and copy/paste can break or miss data.

Select All Data in One Go

Ctrl + Shift + → Select row to end
Ctrl + Shift + ↓ Select column to bottom
Ctrl + A Select all (if in data)
If there are blank cells in your data, this shortcut stops at each blank. Always start from A1 to capture everything.

Saving Your Workbook

Ctrl+S to save. Or File → Save As to choose location. If you use OneDrive, you can turn on AutoSave (toggle at top-left). AutoSave only works for files stored on OneDrive.

The Home tab is where you'll spend most of your time. It has everything for formatting and editing.

Sort & Filter (Home Tab → Editing)

Select your data → Home → Sort & Filter → Filter. This adds dropdown arrows to each column header. You can then filter by value, text, or number conditions.

In the course: We filtered for Data Analyst jobs in the U.S., full-time only, looking at yearly salaries. Filters let you focus on exactly the slice of data you care about.

Insert Tab — Charts & Tables

The Insert tab is the second most-used tab. Key things here:

Charts

Select your data → Insert → Recommended Charts to see what fits best. Or pick from bar, line, pie, histogram, etc.

Tables

Turn data into a proper table (Ctrl+T). This enables structured references and auto-expansion.

Pivot Tables

Advanced data summarization (covered in Ch 5). Instantly aggregate and cross-tabulate data.

Recommended Charts

Excel suggests chart types based on your data. Select data first, then click Recommended Charts.

View Tab — Freeze Panes (Game Changer)

When you scroll down, your column headers disappear! Fix this with Freeze Panes.

Freeze Top Row

Keep row 1 visible while scrolling down.

Freeze First Column

Keep column A visible while scrolling right.

Freeze Panes (custom)

Select cell B2 → Freeze Panes. Locks everything above row 2 AND left of column B.
