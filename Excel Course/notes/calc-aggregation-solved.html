COUNTIFS — Analyst AND US

=COUNTIFS(A2:A7,$L$1,K2:K7,$L$2) — the row must pass BOTH tests.

=COUNTIFS(A2:A7, $L$1, K2:K7, $L$2)  (L1 = "Data Analyst", L2 = "United States")
1

Check BOTH conditions per row

Title = Analyst AND country = US. If either fails → 0.

A — titleK — countryBoth match?
2✓ Analyst✓ US✓ 1
3✗ Scientist✓ US✗ 0
4✓ Analyst✗ India✗ 0
5✗ Engineer✓ US✗ 0

7✓ Analyst✗ UK✗ 0
1 + 0 + 0 + 0 + 1 + 0 = 2

The classic trap: 4 (analysts) + 4 (US) = 8 — WRONG. Each row counts once only if it satisfies both. Adding the two COUNTIFs double-counts row 2 and row 6. The answer is 2.

AVERAGE — total ÷ how many

=AVERAGE(M2:M7) — the SUM of the numbers divided by the COUNT of the numbers.

=AVERAGE(M2:M7)
1

Add the numbers

Same as SUM: 485,000 (blank skipped).

2

Count the numbers

Same as COUNT: 5 numbers.

3

Divide

485,000 ÷ 5 = 97,000.

(100,000 + 150,000 + 45,000 + 130,000 + 60,000) ÷ 5 = 485,000 ÷ 5 = 97,000

AVERAGE is just SUM ÷ COUNT — computed on the SAME numbers. Blank cells vanish from both sides.

AVERAGEIF — Analyst average salary

=AVERAGEIF(A2:A7,$L$1,M2:M7) — average only the matching rows.

=AVERAGEIF(A2:A7, $L$1, M2:M7)  (L1 = "Data Analyst")
1

Find the matching rows

Analysts are rows 2, 4, 6, 7.

2

Add their salaries

100,000 + 45,000 + (blank) + 60,000 = 205,000.

3

Divide by how many had a number

Row 6 is blank → 3 salaries. 205,000 ÷ 3 ≈ 68,333.

(100,000 + 45,000 + (blank) + 60,000) ÷ 3 = 205,000 ÷ 3 ≈ 68,333

Tiny trap: divide by 3, NOT by 4 — the blank salary is excluded from the average, exactly like COUNT would.

5 values → the 3rd one: 115,000. The 960k doesn't move it.

(80,000+95,000+115,000+130,000+960,000) ÷ 5 = 1,380,000 ÷ 5 = 276,000.

(80,000 + 95,000 + 115,000 + 130,000 + 960,000) ÷ 5 = 1,380,000 ÷ 5 = 276,000  ·  MEDIAN = 115,000

Why Luke prefers the median: the single $960k job drags the average from ~115k up to 276k. The median stays at 115k and honestly reflects "a typical salary".
