Excel — IFERROR (Error Handling)
Step by step
Catch every formula error and show something friendly instead

IFERROR

IFERROR = If there's an error, use this instead. When your formula would show #N/A, #DIV/0! or any other error, IFERROR catches it and prints the value you choose. The perfect partner for VLOOKUP and HLOOKUP.

error value fallback result formula / match
1

The Problem — Ugly Error Values

Sometimes a formula just breaks. This is what Excel shows when it does.

WHY IT'S NEEDED
ErrorMeaningExample cause
#N/AValue not found=VLOOKUP(999, A2:D6, 2, FALSE)
#DIV/0!Dividing by zero or an empty cell=C2/B2 where B2 is blank
#VALUE!Wrong data type=A2+B2 where B2 has text
#NAME?Typo in a function or range name=VLOKUP(A2, A2:D6, 2, FALSE)
#REF!Column/row the formula needed was deleted=A2:D6 changed to =A2:D4

Why it matters: errors look scary to your boss and break other formulas that point at them.

2

The Solution — IFERROR Is a Safety Net

Two inputs only: what to check, and what to show if it errors.

=IFERROR(value, value_if_error)
Example valuePartMeaning
C2/B2valueThe formula to try (it may error)
0value_if_errorWhat to show instead if it errors

Analogy: IFERROR is a safety net under a tightrope walker. If the walker falls (error), the net (your fallback) catches them.

3

Simple Example — Dividing By a Blank Cell

The classic #DIV/0! case. Without IFERROR, an empty cell breaks everything.

1

The data — one row has no quantity

We want price per unit in column C: Total ÷ Qty.

ABCD
1ItemQtyTotalPrice/Unit
2Pen10500=C2/B2
3Notebook300=C3/B3
4Eraser5250=C4/B4
2

The error happens

B3 is empty → dividing by empty = dividing by zero.

ABCD
1ItemQtyTotalPrice/Unit
2Pen1050050
3Notebook300#DIV/0!
4Eraser525050
3

Wrap it in IFERROR

Same formula inside, plus a fallback. Now it shows a clean 0 instead.

=IFERROR(C3/B3, 0)
ABCD
1ItemQtyTotalPrice/Unit
2Pen1050050
3Notebook300=IFERROR(C3/B3,0)
4Eraser525050

Row 3 now shows 0 instead of the scary red #DIV/0!

4

Prefer text? Show a message instead of 0

The fallback can be any value — a number, text, or another formula.

=IFERROR(C3/B3, "No sales") → "No sales"

Real-Life Example — VLOOKUP + IFERROR

Search an employee ID. If it doesn't exist, say "Not Found" instead of #N/A.

PERFECT PAIR
1

Employee database + search area

User types an ID in F2; the name appears in G2.

ABCDFG

2

The VLOOKUP alone breaks

ID 999 isn't in the table → #N/A. The formula below shows that in G2.

=VLOOKUP(F2, A2:D6, 2, FALSE) → #N/A
3

Wrap the whole VLOOKUP in IFERROR

The VLOOKUP goes in as the first argument. The message is the fallback.

=IFERROR(VLOOKUP(F2, A2:D6, 2, FALSE), "Not Found")

2999"Not Found"
3103Priya

999 → "Not Found". And 103 still works normally → Priya.

Pattern: =IFERROR(ANY_FORMULA, FALLBACK) — works for VLOOKUP, HLOOKUP, division, or anything else.

IFERROR Catches EVERY Error Type

One net, five kinds of falls. Same formula handles them all.

Error that happensWithout IFERRORWith =IFERROR(A2,B2,"oops")
=VLOOKUP(999, A2:D6, 2, FALSE)#N/Aoops
=1/0#DIV/0!oops
="abc"+5#VALUE!oops
=VLOKUP(A2,...)#NAME?oops
=A2:D6 (deleted)#REF!oops

Remember: IFERROR doesn't care which error it is. Any error → fallback.

7

IFERROR vs IFNA — Choose Wisely

IFNA catches ONLY the "not found" error. IFERROR catches everything.

IFERRORIFNA
Catches #N/A✅ Yes✅ Yes
Catches #DIV/0!, #VALUE!, #NAME?, #REF!✅ Yes❌ No
Best forDivision, calculationsLookups (VLOOKUP/HLOOKUP/XLOOKUP)
Syntax=IFERROR(value, fallback)=IFNA(value, fallback)

Careful with IFERROR on lookups: it also hides real mistakes like a typo in the formula. IFNA only hides the genuine "not found" case, so it's often the safer choice for VLOOKUP.

8

Best Practices — Don't Hide Real Problems

IFERROR is a bandage, not a fix. Use it wisely.

ADVICE
✅ Do❌ Don't
Use IFERROR for lookups & divisionWrap every formula just to silence errors
Return a meaningful message like "Not Found"Return empty "" so you forget the data is missing
Use IFNA for pure lookupsHide #NAME? typos — fix the spelling instead
Lock ranges with F4 before copyingIgnore it when the formula still gives errors

Golden rule: IFERROR shows a friendly message, but a real error is a hint something is wrong with your data. Find the cause first, wrap it second.
