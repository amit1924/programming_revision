Merge & Center Cells

Combine multiple cells into one big title cell

What "Merge" Does

Merging takes a rectangle of cells (like A1:D1) and joins them into one big cell. Perfect for a heading that stretches across several columns — just like a table title.

Only the upper-left cell keeps its content. Everything else (B1, C1, D1) is emptied.

1 Quickest way — via the Menu
  1. 1. Select the cells to merge (e.g. A1:D1).
  2. 2. Go to Format → Merge Cells → Merge and Center Cells.
  3. 3. Done — the text is merged and centered in one step.

Note: If your version only shows Format → Merge Cells → Merge Cells (without the "Center" option), merge first, then center the text using the alignment tools in Lesson 2.

2 Via the Toolbar
  1. 1. Select the cells to merge (e.g. A1:D1).
  2. 2. Click the Merge Cells button ( it looks like two cells merging together).
  3. 3. Choose Merge and Center Cells from its small dropdown if available.

Other Merge Options

Merge Cells

Joins the cells but keeps horizontal alignment (doesn't center automatically).

Merge and Center Cells

Joins cells AND centers the content — the usual choice for titles.

Merge Cells in Rows

Merges each selected row separately into one cell per row.

Unmerge Cells

Reverses the merge — splits the big cell back into separate cells (only top-left keeps the text).

Heads up! If the selected cells already contain data, LibreOffice will warn that only the upper-left cell's content will be kept. Click Yes only if that's really what you want — otherwise you'll lose the other cells' data.

Alignment Settings

Position your text & numbers anywhere inside a cell

Where to Find It

Select your cell(s) → Format → Cells → Alignment, or use the alignment buttons straight from the toolbar.

Horizontal Alignment

Default

Text goes left, numbers go right. The automatic behavior.

Center

Centers content horizontally. Best for titles & headers.

Right

Aligns to the right — standard for numbers.

Left

Aligns to the left — natural for plain text.

Justified

Stretches text to reach both the left and right edges.

Filled / Distributed

Repeats or evenly spaces the content across the whole cell.

Vertical Alignment

Top

Content sits at the top of the cell.

Middle

Centers vertically — looks best with headers & titles.

Bottom

Content at the bottom of the cell (the default).

Text Properties & Orientation

Text Orientation

Rotate text (e.g. 45°, 90°) or stack it vertically for narrow columns.

Wrap Text Automatically

Long text flows onto multiple lines inside the cell instead of spilling out.

Shrink to Cell Size

Auto-reduces the font size so the text fits without wrapping.

Indent

Adds spacing before text when using left alignment — great for sub-items.
