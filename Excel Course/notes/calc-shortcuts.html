Full Shortcut Cheat Sheet

Moving Around
  • ← → ↑ ↓ Move one cell
  • Ctrl + ← Jump to edge of data
  • Ctrl + Home Jump to A1
  • Ctrl + End Last used cell
  • PgUp / PgDn Scroll a screen
Selecting
  • Shift + Arrow Extend select
  • Ctrl + A Select all
  • Shift + Space Select row
  • Ctrl + Space Select column
Edit & Clipboard
  • Ctrl + C / X / V Copy · Cut · Paste
  • Ctrl + Z / Y Undo / Redo
  • F2 Edit cell
  • Esc Cancel
Data & Filling
  • Ctrl + ; Insert date
  • Ctrl + Shift + ; Insert time
  • Ctrl + D Fill down
  • Ctrl + R Fill right
  • Ctrl + Enter Fill selection
Find & Tools
  • Ctrl + F Find
  • Ctrl + H Find & Replace
  • F4 Cycle $ refs
  • Ctrl + 1 Format Cells
Workbook & Sheets
  • Ctrl + N / O / S / P New · Open · Save · Print
  • Ctrl + W Close sheet
  • Shift + F11 New sheet
  • Ctrl + PgDn / PgUp Next / Prev sheet

How to Actually Remember Them

Learn 3 per day, not 30. Just 10 shortcuts cover 80% of daily work: Ctrl+CCtrl+VCtrl+ZCtrl+SCtrl+FF2Ctrl+EnterCtrl+D. Every time you reach for the mouse, force the key instead — practice makes permanent.
