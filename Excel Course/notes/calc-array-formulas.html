Arrays in Excel

An array is a collection of values treated as one thing. An array formula performs calculations across that collection — typing a formula in a single cell lets it fill the cells below or beside it, or collapse a whole range into one number. Modern Excel does this with dynamic arrays (just press Enter); older workbooks used legacy CSE (Ctrl+Shift+Enter).

The two flavours of array formula

An array formula either returns a single result (it performs several calculations to generate one answer) or multiple results (one formula fills several cells). Both work on the same idea: the formula processes every value in the array at once.

=SUM(A2:A9*B2:B9) → one total, from thousands of row-by-row products
2

How Arrays Think — the ROW Trick

Same function, two answers: normal entry returns one value, array entry returns them all.

FormulaEntered normallyEntered as an array
=ROW(A1:A10)1{1, 2, 3, …, 10}
=SUM(ROW(A1:A10))155

Why? In normal mode, ROW(A1:A10) returns just the first row number (1). Force the whole range into the calculation and it returns the array {1…10}, which SUM then adds to 55. This is the whole point: array formulas feed an entire collection into a single calculation.

=SUM(ROW(A1:A10)) → 55

Note: with dynamic arrays you don't enter this with CSE anymore — the ROW trick is how legacy arrays thought. In 365, the same formula spills automatically. Use SEQUENCE(10) to get {1…10} directly.

Array Constants — Hand-Typed Arrays

Write an array straight into a formula with { } — commas separate columns, semicolons start a new row.

{ } NOTATION

{1;2;3;4;5}A 5×1 vertical column (semicolons = new row)

1

Turn a spill range into a constant

Select the top-left cell of a dynamic array, press F2 to edit, then F9 — Excel converts the cell references into a literal {…} constant you can paste anywhere. Handy when you want the numbers, not the formula.

Key point: you type the braces yourself — they are not the CSE braces. The CSE { } are added by Excel when you press Ctrl+Shift+Enter; the constant { } you type as part of the formula.

Array Multiplication & Boolean Logic

Multiply two arrays element by element, then let TRUE/FALSE act like 1/0.

THE ENGINE

=SUM(A2:A6*B2:B6) → 55

Line by line: 1×1=1, 2×2=4, 3×3=9, 4×4=16, 5×5=25 — added up that's 55. The same "sum of the products" is what SUMPRODUCT(A2:A6, B2:B6) gives without the array ceremony.

1

Booleans are the real superpower

In Excel math, TRUE = 1 and FALSE = 0. So (title="Data Analyst") is really an array of 1s and 0s. Multiply two conditions together and you get 1 only when BOTH are true — a filter inside a formula.

=SUM((A2:A9="Data Analyst")*(C2:C9="United States")) → 2

Counts Data Analysts in the US: two rows match both conditions → 1+1+0+0+0+0+0+0 = 2. This is the pattern behind conditional sums, medians and counts without a COUNTIFS/SUMIFS in sight.

The Dynamic Array Functions

The new family that made CSE obsolete: FILTER · SORT · SORTBY · UNIQUE · SEQUENCE · RANDARRAY.

365 ONLY
FunctionWhat it returnsExample (on our 8 jobs)
UNIQUE(rng)Distinct values from a range=UNIQUE(A2:A9) → 5 job titles
SORT(rng)Range sorted (default ascending)=SORT(UNIQUE(A2:A9)) → alphabetical titles
SORTBY(rng, by)Sort by a separate column=SORTBY(A2:A9, B2:B9, -1) → titles by salary, high→low

The course's easy problem: type =UNIQUE(A2:A9), press Enter, and every unique job title spills down. Wrap it in SORT to get them alphabetical. One formula, many answers, zero dragging.

Spilling & the # Operator

A dynamic array formula "spills" results into neighbors; reference the whole spill with a hash.

SPILL RANGE
=SEQUENCE(10) → spills A2:A11, then…
=SUM(A2#) → 55
ConceptMeaning
SpillA formula returns several values and Excel places them into the neighboring cells automatically
Spill rangeThe block of cells the dynamic formula fills (highlighted with a border when selected)
# operatorA2# = "everything the formula in A2 spilled" — same as A2:A11, but it grows/shrinks automatically
Top-left is the bossOnly the first cell holds the formula; the spilled cells are "ghosted" in the formula bar and can't be edited

Why it beats a fixed range: =SUM(A2:A11) breaks if the spill grows to 20 rows. =SUM(A2#) follows the spill wherever it goes — no manual updates. You can chain it: =FILTER(C2#, LEN(C2#)>3) feeds one spill into the next.

Limitations: the # operator doesn't support closed workbooks (returns #REF! until you open it), and spilled formulas can't live inside Excel tables — keep them in the grid.

#SPILL! and Other Array Error Values

When a dynamic array can't spill, or a legacy array doesn't fit.

TROUBLESHOOT
ErrorCauseFix
#SPILL!Something already sits in the spill range (Excel shows a dotted border around the blocker)Clear or move the blocking cells — the formula spills on its own
#N/ALegacy array's output range is too big for the pre-selected cellsSelect a larger output range and re-enter
#REF!Spill reference points at a closed workbookOpen the source workbook
@ operatorYou need ONE value, not the whole array=@A2:A9*10% forces "implicit intersection" — same row as the formula

Implicit intersection (@): older formulas sometimes return an array where a single value is expected. Excel inserts @ automatically to shrink it to one value. If a spilled formula surprises you by filling too many cells, @ pulls it back to the row it's in.

9

Legacy CSE Arrays in the Wild

The "classical arrays" from before ~2020 — how to spot, edit and survive them.

ENCOUNTER THEM
1

Select the output range FIRST

Before typing anything, highlight every cell that will hold a result. The formula is entered in the top-left cell of the selection.

2

Press Ctrl+Shift+Enter

Not plain Enter. Excel wraps the formula in curly braces {=A2:A6*B2:B6} and fills every selected cell.

3

Treat the block as one unit

You can't edit a single cell — press Enter in one and Excel refuses. Resize by re-selecting the new range and re-entering the formula with CSE. Add a row and it won't follow automatically.

{=A2:A6*B2:B6} ← entered with Ctrl+Shift+Enter, braces added by Excel

Upgrading: Microsoft says legacy CSE "should no longer be used". To convert: copy the formula text, delete the whole legacy array range, re-enter it in the top-left cell, and press plain Enter — it becomes a dynamic array that spills for you.

CSE breakup: legacy formulas that depended on each other could calculate "cell by cell" and produce inconsistent results. Dynamic arrays report a circular reference instead — much easier to debug.

Conditional Median with an IF Array

The medium problem: transform any function into its "…IF" version.

THE COURSE
ABC
1Job TitleSalaryCountry
2Data Analyst115000United States
3Data Analyst75000United States
4Data Analyst90000India
5Data Scientist95000United States
6Data Scientist960000United States
7Data Engineer120000India
8Business Analyst60000United Kingdom
9Senior Data Engineer140000United States
=MEDIAN(IF((A2:A9="Data Analyst")*(B2:B9<>""), B2:B9)) → 90,000
1

Build the filter with booleans

(A2:A9="Data Analyst") → an array of TRUE/FALSE. Multiply by (B2:B9<>"") to also drop blank salaries. Only rows where both are TRUE produce a 1.

2

Swap the 1/0 for the salary with IF

IF(0/1, salary) returns the salary when the condition is TRUE and blank when FALSE — giving an array of only the Data Analyst salaries: {115000, 75000, 90000, blank…}.

3

Wrap it in MEDIAN

Sorted: 75,000 · 90,000 · 115,000 → the middle value is 90,000. The same trick powers MODE (no MODEIF exists!) and any function without an "…IF" sibling.

The course's rule: "That's how you transform any function in Excel that doesn't have a COUNTIF / AVERAGEIF version into other functions." Median had no MEDIANIF — so we build the array ourselves. In a pivot table it runs for every title at once (Business Analyst → 85,000, etc.).

SUMPRODUCT & the Double-Unary

The hard problem: count job postings per month with one array formula.

-- CONVERTER
ABD
1Job TitleSalaryPosted Date
2Data Analyst1150002023-01-05
3Data Analyst750002023-01-18
4Data Analyst900002023-02-02
5Data Scientist950002023-01-27
6Data Scientist9600002023-02-11
7Data Engineer1200002023-03-06
8Business Analyst600002023-01-30
9Senior Data Engineer1400002023-03-15
=SUMPRODUCT(--(TEXT(D2:D9,"mmmm")="January")) → 4
1

Extract the month as text

TEXT(D2:D9,"mmmm") turns every date into its full month name ("January", "February", …) — one array of 8 text values.

2

Compare to the month you want

=…="January" → an array of TRUE/FALSE. But SUMPRODUCT won't add raw TRUE/FALSE — it returns 0.

3

Coerce with the double-unary --

-- negates twice: TRUE → −1 → 1, FALSE → 0 → 0. Now it's an array of 1s and 0s that SUMPRODUCT adds up. January has 4 postings in our mini data.

Why SUMPRODUCT? It sums an array's products safely in every Excel version, old or new — in pre-dynamic-arrays Excel, SUM couldn't handle an array without CSE. So SUMPRODUCT is the portable way to give a result to someone on an older version. (In the real dataset January = 3,102 postings.)

The extra column shortcut: you could also add a helper column of =TEXT(D2,"mmmm") and COUNTIF it — same answer, less magic. The array version just does it without the helper column.
