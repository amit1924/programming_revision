Pivot Table Intro

Insert • Rows • Columns • Values • Filters
Creating a Pivot Table

Select any cell in your data → Insert → PivotTable (or Recommended PivotTables).

Choose New Worksheet or Existing Worksheet.

PivotTable Fields pane:
Rows → Columns → Values → Filters

Drag fields between the four areas to rearrange your analysis.

Value Field Settings

Right-click any value → Value Field Settings to change:

Sum Adds all values (default for numbers)
Count Counts rows (default for text)
Average Mean of values
Max/Min Highest/lowest value

Rename the field in the Custom Name box for cleaner labels.

PivotTable Design

When a pivot table is selected, the Design tab appears with:

Subtotals Grand Totals Report Layout Blank Rows PivotStyles

Report Layout → Show in Tabular Form (spreadsheet-like).

PivotTable Styles — Choose a color scheme for banded rows and headers.

Pivot Chart Basics

Select a pivot table → Insert → PivotChart (or PivotTable Analyze → PivotChart).

Pivot charts inherit the pivot table's layout. Drag fields directly on the chart to rearrange.

Pro Tips
Refresh — Pivot tables don't auto-refresh when source data changes. Right-click → Refresh (or Alt+F5).
Formatting — Right-click a value → Number Format to set currency, %, decimals without changing data.
Defer Layout Update — In the Fields pane check "Defer Layout Update" while you rearrange fields, then click Update.
Double-click a value — Drills down to show the raw data behind that number on a new sheet.
Grand Total — Design → Grand Totals → Off for Rows/Columns to hide if redundant.
Sort by Value — Right-click any value → Sort → Largest to Smallest. Much easier than sorting row labels.
