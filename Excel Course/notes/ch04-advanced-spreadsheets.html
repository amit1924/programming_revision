Structured References@ COLUMN

Instead of =SUM(A2:A100), tables let you use column names:

FormulaWhat it does
=SUM(jobs[Salary])Sum of Salary column in "jobs" table
=jobs[@Salary]Value from current row's Salary column
=AVERAGE(jobs[Salary])Average of all salaries
=COUNTIF(jobs[Title],"*Analyst")Count titles ending in "Analyst"

The @ means "this row". Formulas are much easier to read!

Protect SheetREVIEW TAB

Steps to protect a sheet with one editable cell:

1. Select all cells → Ctrl+1 → Protection tab → uncheck Locked
2. Select cell you want editable → Ctrl+1 → check Locked
3. Review → Protect Sheet → (optional password) → OK
Result: Only the locked cell can be edited!

Pro Tips
Ctrl+T — Create a table in one keystroke from any selected cell.
Clear Rules — Conditional Formatting → Clear Rules → Entire Sheet to start over.
Manage Rules — Conditional Formatting → Manage Rules to view, edit, or delete rules.
Table Names — Name your tables meaningfully (e.g., jobs, salary) for cleaner formulas.
Multi-column Slicer — Right-click slicer → Size & Properties → change number of columns to 2 or 3.
Data Validation Error — Uncheck "Show error alert" in Data Validation options for a cleaner user experience.
