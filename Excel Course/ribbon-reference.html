Data Tab

Get Data · Refresh · Sort · Filter · Forecast · Outline · Analysis
Get Data (Power Query)DATA

Import from files, databases, web, or other sources. Power Query cleans and transforms data on the way in.

Data → Get Data → From File / Database / Web → follow the wizard.

Refresh AllDATA

Re-run all queries and update pivot tables with the latest data from the source. Essential after source data changes.

Data → Refresh All (or Ctrl + Alt + F5)
